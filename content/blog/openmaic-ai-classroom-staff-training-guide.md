신입 직원이 첫날 들어왔습니다. 업무 매뉴얼을 건네줬습니다. 이틀이 지났는데 같은 질문이 반복됩니다.

"이 서류는 어디에 올려요?" "이 제품 설명은 어떻게 해요?"

담당자는 자기 일을 내려놓고 하루 절반을 교육에 씁니다. 작은 회사일수록 이 구조가 가장 버겁습니다. 강사를 외부에서 부르기엔 비용이 부담스럽고, 교육 영상을 직접 만들기엔 장비도 시간도 없습니다.

그런데 중국 청화대학교가 만든 AI가 이 문제를 조용히 해결하고 있습니다.

![center](/mascot/md/emotion/cat_happy.png)

## OpenMAIC — 문서를 읽어주는 AI 강사의 정체

OpenMAIC(오픈메이크)는 청화대학교 연구팀이 공개한 무료 오픈소스 AI 교육 플랫폼입니다.

쉽게 설명하면 이렇습니다. 업무 매뉴얼, 제품 설명서, 교육 자료를 업로드하면 여러 AI 에이전트가 선생님·조교·토론 파트너 역할을 나눠 맡습니다. 직원이 자료를 '읽는' 게 아니라 AI와 '대화하며' 배우는 방식이죠. 직원이 질문하면 AI가 답하고, 이해 확인 퀴즈를 내고, 틀리면 다시 설명합니다.

청화대학교는 이 방식을 2년간 실제 강의에 적용해 검증했습니다. 2026년 8월 27일 정식 버전(v1.0.0)을 공개한 첫날, GitHub 별을 2,819개 받았습니다. 지금은 별 25,975개 이상으로, GitHub 트렌딩 1위에도 올랐습니다.

![OpenMAIC GitHub 반응 타임라인](/images/blog/openmaic-ai-classroom-staff-training-guide-fig1.svg)

그렇다면 우리 회사에서 쓰려면 준비가 얼마나 필요할까요?

| 항목 | 온라인 체험 (openmaic.io) | 자체 서버 설치 (GitHub) |
|------|--------------------------|------------------------|
| 비용 | 무료 (현재 기준) | 서버 비용만 (오픈소스 자체 무료) |
| 설치 여부 | 불필요 | Python 환경 설정 필요 |
| 데이터 위치 | 외부 클라우드 서버 | 우리 회사 서버 내부 |
| 권장 대상 | 체험·소규모 | 민감 문서·장기 운영 |

민감한 인사 규정이나 영업 전략 문서라면 자체 서버 설치가 더 안전합니다. 문서 내용이 외부 서버로 넘어가지 않으니까요.

## 우리 회사에서 쓰는 법 — 3가지 시나리오

기술 얘기처럼 들릴 수 있습니다. 그런데 실제 활용 방법은 생각보다 단순합니다.

![center](/mascot/md/emotion/cat_thinking.png)

**시나리오 ① — 신입 직원 온보딩**

업무 매뉴얼, 직원 수칙, 첫 주에 알아야 할 내용을 OpenMAIC에 올립니다. 신입에게는 세션 링크 하나를 줍니다. AI가 내용을 설명하고, 질문을 받고, 이해 퀴즈를 냅니다. 담당자가 옆에 붙어있지 않아도 됩니다. 교육이 끝나면 직원이 실제로 이해했는지도 확인할 수 있습니다.

**시나리오 ② — 영업 직원 제품 교육**

취급 제품이 많으면 영업 직원도 다 외우기 힘듭니다. 제품 카탈로그와 스펙 시트를 올리면 AI가 트레이너 역할을 합니다. "이 제품이 경쟁 제품과 어떻게 다른가요?" 같은 질문에도 문서를 기반으로 바로 답합니다. 신입 영업 직원뿐 아니라 기존 직원 복습에도 씁니다.

**시나리오 ③ — 규정·컴플라이언스 교육**

개인정보 처리 방침, 안전 수칙, 직장 내 괴롭힘 예방 교육처럼 의무이지만 아무도 집중하지 않는 교육 — OpenMAIC에 규정집을 올리면 AI가 퀴즈를 내고 직원 한 명 한 명의 이해 여부를 확인합니다. "혹시 이해 못 한 부분 있나요?"를 사람이 아닌 AI가 물어봅니다.

![OpenMAIC 중소기업 3가지 활용 시나리오](/images/blog/openmaic-ai-classroom-staff-training-guide-fig2.svg)

직원 교육의 핵심은 전달이 아니라 이해입니다. 자료를 넘겨주는 건 전달이고, AI가 질문에 답하며 퀴즈를 내는 건 이해를 확인하는 루프입니다. 작은 회사일수록 교육을 반복할 여력이 없습니다. (주)비젼솔루션은 AI 교육 도구가 중소기업에 줄 수 있는 가장 실용적인 가치가 바로 이 "이해 확인" 구조라고 봅니다.

## 지금 바로 실습하는 방법

복잡한 설치 없이 온라인에서 바로 써볼 수 있습니다.

**① openmaic.io 접속**: 브라우저에서 바로 실행합니다. 회원가입 없이 바로 체험할 수 있습니다.

**② 문서 업로드**: PDF, Word, 텍스트 파일을 올립니다. 테스트용으로 회사 소개서나 제품 설명서 한 장이면 충분합니다.

**③ 학생 역할로 대화**: AI가 강의를 만들면 직접 학생이 되어 대화해봅니다. 어떤 질문에 어떻게 답하는지 확인해보세요.

직접 설치해서 회사 서버에 올리고 싶다면 GitHub에서 무료로 받을 수 있습니다:
