오후 9시, 대표님은 탭 세 개를 동시에 열어둡니다.

하나는 인스타그램 콘텐츠 기획, 또 하나는 경쟁사 가격 조사, 마지막은 다음 달 매출 예측입니다. "ChatGPT한테 시키면 되지 않나?" 싶었는데, 결과물이 너무 교과서적입니다. 우리 회사 상황을 모르니까요. 그렇다고 마케터를 뽑기엔 부담스럽고, 재무 담당자를 두기엔 규모가 애매합니다.

그사이 GitHub에서 이상한 프로젝트 하나가 불을 뿜었습니다. 며칠 만에 별 5만 개를 돌파하며 X(트위터), TikTok, Reddit을 동시에 달궜습니다.

**"마케터 수십 명, 엔지니어 수십 명, 리서처, 재무 담당자까지 — AI 전문가 232명을 원클릭으로 무료 설치."**

이름은 **Agency Agents**입니다.

![center](/mascot/md/emotion/cat_surprised.png)

## AI 비서 하나 vs AI 팀 232명, 뭐가 다를까요

ChatGPT나 Claude 같은 일반 AI는 "뭐든 대답하는 만능 직원"입니다.

만능이 곧 전문성 없음을 뜻한다는 게 문제입니다. 법무 검토를 부탁하면 교과서 수준 답변이 나오고, 마케팅 카피를 요청하면 어디서 본 듯한 문구가 나옵니다. AI한테 시켰는데도 결과물을 다시 손봐야 하는 아이러니가 생깁니다.

Agency Agents는 다릅니다. 각 AI에게 구체적인 정체성, 업무 방식, 납품 기준, 성공 지표를 부여합니다. 인스타그램 전담 AI는 릴스 트렌드와 해시태그 전략만 파고들고, 재무 AI는 현금흐름 분석 방식으로만 작동합니다. 범용 AI 비서 하나에게 "오늘은 마케터처럼 행동해줘"라고 부탁하는 것과, 처음부터 마케터로 설계된 AI에게 일을 맡기는 것의 차이입니다.

이 프로젝트는 GitHub에서 MIT 라이선스로 공개됐습니다. 누구나 무료로 쓸 수 있고, 코드를 뜯어고쳐도 됩니다. 현재 GitHub 별 10만 개 이상을 받으며 전 세계 AI 개발자 커뮤니티에서 화제입니다.

## 지금 무료로 설치할 수 있는 도구 — 솔직한 사양과 한계

**도구 두 가지, 모두 무료입니다**

| 도구 | 용도 | 링크 |
|------|------|------|
| **agency-agents** | AI 에이전트 정의 파일 232개 모음 | [github.com/msitarzewski/agency-agents](https://github.com/msitarzewski/agency-agents) |
| **agency-agents-app** | 원클릭 설치 네이티브 앱 | [agencyagents.app](https://agencyagents.app/) |

**필요한 환경**

Agency Agents 자체는 마크다운 파일 모음입니다. 이 파일을 읽어주는 AI 코딩 도구가 하나 필요합니다.

| AI 도구 | 비용 | Agency Agents 지원 |
|---------|------|-------------------|
| Claude Code | 월 $20 또는 API 종량제 | 원클릭 설치 ✓ |
| Cursor | 월 $20 | 원클릭 설치 ✓ |
| GitHub Copilot | 월 $10 | 지원 ✓ |
| Gemini CLI | 무료 (할당량 내) | 지원 ✓ |

총 14개 AI 코딩 도구와 연동됩니다.

**솔직한 한계**

Agency Agents는 코딩 AI 도구에 최적화됐습니다. Claude Code, Cursor 같은 개발 보조 도구를 중심으로 설계됐어요. 코드 작성 업무가 전혀 없는 순수 소상공인이라면 엔지니어링 영역 에이전트는 활용도가 낮을 수 있습니다.

그래도 마케팅, 리서치, 재무, 운영 에이전트는 비개발자도 충분히 활용 가능합니다.

**다른 선택지와 비교**

| 방식 | 장점 | 단점 |
|------|------|------|
| Agency Agents (이 도구) | 무료, 역할 특화, 오픈소스 | AI 도구 구독 별도 필요 |
| ChatGPT Team | 팀 협업 기능 내장 | 월 $25/인, 역할 특화 없음 |
| Claude.ai Pro | 브라우저 기반, 설치 불필요 | 에이전트 역할 직접 정의 필요 |
| 프리랜서 고용 | 진짜 사람의 창의력 | 비용·일정 관리 부담 |

## 우리 회사 업무에 어떻게 연결하나요

**시나리오 1 — 쇼핑몰 운영하는 소매업체**

직원 3명이 운영하는 의류 쇼핑몰을 상상해보세요. Agency Agents에서 인스타그램 전담 AI(`marketing-instagram-curator`)를 설치하고 이렇게 씁니다.

```
너는 인스타그램 마케팅 전문가야.
우리 브랜드는 20~30대 여성 타겟 감성 캐주얼이야.
이번 주 신상 5종의 제품 설명이 여기 있어. [제품 설명 붙여넣기]
릴스 캡션 3개, 해시태그 20개, 최적 업로드 시간을 추천해줘.
```

범용 AI에게 똑같이 물으면 교과서 답변이 돌아옵니다. 인스타그램 전담 에이전트는 릴스 트렌드, 해시태그 전략, 참여율 높은 콘텐츠 형식을 배경 지식으로 갖고 시작합니다.

**시나리오 2 — 경쟁사 리서치 자동화**

리서치 전담 AI(`researcher-trend-researcher`)에게 이렇게 시킬 수 있습니다.

```
우리 업종: 국내 중소 IT 솔루션 제조사
경쟁사 3곳의 최근 6개월 홈페이지와 SNS를 분석해줘.
주요 메시지 변화, 신제품 동향, 고객 반응 패턴을 리포트로 정리해줘.
```

**내 회사 데이터 연결하기**

어떤 에이전트든 우리 회사 맥락을 먼저 알려주면 훨씬 정확해집니다. Claude Code 기준으로 프로젝트 폴더에 `CLAUDE.md` 파일을 만들고 회사 기본 정보를 적어두세요.

```
회사명: 우리 떡볶이
업종: 소규모 분식 프랜차이즈 (3개 지점)
주요 고객: 10~30대 직장인·학생
현재 고민: SNS 팔로워 정체, 배달 주문 단가 낮음
```

이 파일이 있으면 어떤 에이전트든 우리 회사 사정을 기본값으로 깔고 답변합니다.

데이터베이스 연동이나 자동 발송 같은 깊은 커스텀은 개발 작업이 필요합니다. 이 부분은 전문 파트너와 상의하는 게 현실적이에요.

## 5분 실습 — 원클릭 설치부터 첫 대화까지

**준비물**: PC(Windows, macOS, Linux 모두 가능) + Claude Code 또는 Cursor 계정

**1단계 — 앱 다운로드**

[agencyagents.app](https://agencyagents.app/) 에 접속해서 운영체제에 맞는 파일을 받습니다.
- Windows: `.exe` 설치 파일
- macOS: `.dmg` 파일
- Linux: `.AppImage` 또는 `.deb`

**2단계 — AI 도구 선택**

앱을 열면 Claude Code, Cursor, GitHub Copilot 등 지원 도구 목록이 나옵니다. 이미 쓰고 있는 도구를 선택하세요.

**3단계 — 에이전트 설치**

마케팅, 리서치, 재무 등 카테고리를 보고 필요한 에이전트를 클릭하면 선택한 AI 도구에 자동으로 설치됩니다. Git 클론이나 터미널 명령어 없이 클릭 한 번으로 끝납니다.

**4단계 — 첫 프롬프트 실행**

Claude Code나 Cursor를 열고 아래 문장을 그대로 붙여넣어 보세요.

```
안녕, 나는 직원 5명 소규모 카페를 운영하는 대표야.
우리 카페 인스타그램 계정 팔로워가 800명인데 3개월째 정체 중이야.
이번 달 해볼 수 있는 게시물 아이디어 5개와 해시태그 전략을 제안해줘.
```

처음엔 어색하더라도 한 번 써보면 "아, 이게 다른 거구나" 느낌이 금방 옵니다.
