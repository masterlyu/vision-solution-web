## 진짜 쓸 수 있나요? — 현실 요구사항과 장단점

솔직하게 얘기하겠습니다. MiMo V2.5-Pro는 두 가지 방식으로 접근할 수 있고, 상황에 따라 선택이 달라집니다.

![center](/mascot/md/emotion/cat_thinking.webp)

**방법 1 — MiMo API 사용 (초보자 권장)**

샤오미가 운영하는 API 플랫폼([mimo.mi.com](https://mimo.mi.com/))을 이용하는 방법입니다. 내 컴퓨터 사양은 상관없습니다. 서버는 샤오미가 운영합니다. 무료 플랜으로 시작할 수 있고, 사용량이 늘면 유료로 전환하면 됩니다.

단점은 명확합니다. 데이터가 샤오미 서버를 거칩니다. 고객 개인정보나 영업 기밀을 입력해서는 안 됩니다.

**방법 2 — 직접 설치 (보안 요건이 높은 회사)**

HuggingFace에 모델 가중치가 공개되어 있어 자체 서버에 설치할 수 있습니다. 데이터가 외부로 나가지 않아 보안 규정이 엄격한 업종(의료·법률·금융)에 적합합니다.

다만, 제대로 된 속도를 내려면 NVIDIA GPU 24GB VRAM 이상의 서버가 필요합니다. 처음 도입하는 중소기업이라면 API 방식으로 먼저 테스트해보는 것이 현실적입니다.

| | MiMo API | Claude API | OpenAI API |
|---|---|---|---|
| 초기 비용 | 무료 플랜 | 유료 | 유료 |
| 라이선스 | MIT (무료) | 상용 | 상용 |
| 컨텍스트 | 100만 토큰 | 200k | 128k |
| 코딩 특화 | ✅ 특화 | 범용 | 범용 |
| 자체 설치 | 가능 | 불가 | 불가 |

그럼 실제로 어떤 업무에 붙일 수 있는지 보겠습니다.

## 중소기업 활용 시나리오 3가지

MiMo가 잘하는 것은 코드 생성과 자동화입니다.

**홈페이지 코드 자동 생성**

"우리 홈페이지에 무료 견적 폼 추가해줘"라고 입력하면 HTML·CSS 코드를 생성해줍니다. 개발자에게 따로 요청하지 않아도, 코드를 받아 홈페이지에 붙이면 됩니다. 영어로 요청할 때 결과가 더 정확합니다.

**엑셀·반복 업무 자동화 스크립트**

매일 파일을 정리하거나 이메일에서 데이터를 뽑는 업무에 자동화 스크립트를 만들어달라고 할 수 있습니다. 파이썬을 몰라도 됩니다. 코드를 주면 실행 방법도 단계별로 설명해줍니다.

**사내 AI 챗봇 기반**

고객 문의에 자동으로 답하는 챗봇을 MiMo 기반으로 구축할 수 있습니다. 상용 API 대비 비용이 낮아 운영 비용을 줄이면서 챗봇을 유지할 수 있습니다. 자사 FAQ 데이터나 제품 정보를 연결하면 우리 회사에 맞는 응답을 만들 수 있습니다.

자사 시스템과 연결하거나 더 복잡한 자동화 구조를 원한다면, 그 단계부터는 설계 전문가가 필요합니다.

## MiMo API, 5분 만에 시작하기

![MiMo API 5분 시작법](/images/blog/xiaomi-mimo-v25-pro-free-coding-agent-fig2.svg)
*▲ MiMo API 5분 시작 3단계 · 출처: mimo.mi.com*

따라해보세요. 어렵지 않습니다.

**1단계 — 가입 및 API 키 발급**

1. [mimo.mi.com](https://mimo.mi.com/) 에 접속합니다
2. 무료 계정을 만듭니다 (이메일 인증 필요)
3. 대시보드에서 API 키를 발급받습니다

**2단계 — 첫 코딩 요청**

아래 프롬프트를 그대로 복붙해서 테스트해보세요:

```
Please create an HTML contact form with the following fields:
- Name (이름)
- Phone number (연락처)
- Inquiry content (문의 내용)
- Submit button (제출 버튼)

Style it cleanly with CSS so it works well on mobile devices.
```

*팁: MiMo는 코딩 요청을 영어로 입력할 때 더 정확한 결과를 냅니다.*

**3단계 — 결과물 적용**

생성된 HTML 코드를 홈페이지 담당자에게 전달하거나, 직접 홈페이지 파일에 붙여넣으면 됩니다. 수정 없이도 바로 작동합니다.

### 자주 묻는 질문

**Q. 한국어로 요청해도 되나요?**
A. 됩니다. 다만 코딩 관련 요청은 영어로 입력할 때 결과가 더 정확합니다. 방향을 설명하거나 간단한 질문은 한국어도 무방합니다.

**Q. 내 데이터는 안전한가요?**
A. API 방식은 입력한 내용이 샤오미 서버를 거칩니다. 고객 개인정보나 영업 기밀은 절대 입력하지 마세요. 보안이 중요하다면 자체 서버 직접 설치 방식을 검토하세요.

**Q. Claude나 ChatGPT를 완전히 대체할 수 있나요?**
A. 코딩·자동화 스크립트 생성에서는 충분한 대안입니다. 마케팅 카피 작성, 아이디어 발굴, 자유로운 대화형 업무는 범용 AI가 여전히 강점입니다. 용도에 맞게 병행 사용하는 것이 현실적입니다.
