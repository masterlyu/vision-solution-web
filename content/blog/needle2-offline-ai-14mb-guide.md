## Needle2가 뭔가요? — 14MB로 진짜 AI가 됩니다

![center](/mascot/md/emotion/cat_happy.png)

Needle2는 미국 스타트업 cactus-compute가 개발한 초소형 오픈소스 AI 언어 모델입니다. 핵심 수치만 보면 이렇습니다.

![Needle2 핵심 수치](/images/blog/needle2-offline-ai-14mb-guide-fig1.svg)
*▲ Needle2 핵심 수치 · 출처: github.com/cactus-compute/needle, aitoolly.com 2026-08-16*

파라미터 수는 4,500만 개(45M)입니다. ChatGPT(GPT-4)가 수천억 개인 것과 비교하면, 비교가 안 되게 작습니다. 그런데 이 작음이 강점입니다. 모델 파일 전체가 **14MB** — 스마트폰 앱 하나보다 작습니다.

속도도 놀랍습니다. 10만 원 안팎의 라즈베리파이5에서 **초당 500 토큰**을 처리합니다. 저가형 안드로이드 스마트폰에서는 **300~700 토큰/초**입니다. "토큰"을 쉽게 말하면 단어나 음절 단위입니다. 초당 500 토큰이면 사람이 읽는 속도보다 빠르게 답변이 나옵니다.

설치는 단 한 줄입니다.

```bash
pip install cactus-needle
```

서버도 없고, 계정도 없고, 요금도 없습니다. 도구 호출(tool calling)과 구조화 데이터 추출(JSON 출력)도 기본 지원합니다.

## 우리 회사에서 어떻게 써요? — 3가지 현장 시나리오

![center](/mascot/md/emotion/cat_thinking.png)

Needle2가 좋다는 건 알겠는데, 내 사업장 어디에 붙이는지가 진짜 궁금한 부분입니다. 세 가지 시나리오를 실제 업무 흐름으로 풀어보겠습니다.

### ① POS 단말·키오스크에 FAQ 자동 처리

매장에서 손님이 주문 중 자주 묻는 말이 있습니다. "할인 조건이 어떻게 돼요?", "포인트 적립은요?", "주차는요?" — 직원이 반복해서 답해야 하는 질문들입니다.

**도입 전**: 직원 1명이 카운터에서 주문받으며 동시에 이런 질문들을 처리합니다. 바쁜 시간대엔 고객 대기 줄이 길어집니다.

**도입 후**: Needle2를 키오스크나 POS 단말에 올려두면, 이 질문들을 AI가 오프라인에서 바로 답합니다. 와이파이가 끊겨도 됩니다.

### ② 공장 설비 옆 라즈베리파이로 이상 감지

설비 옆에 라즈베리파이 하나를 붙여두고, 온도·진동·전류 수치를 실시간으로 읽혀줍니다. Needle2가 구조화된 JSON 출력으로 "정상/주의/위험"을 자동 판단합니다.

클라우드 AI라면 센서 데이터를 인터넷으로 내보내야 합니다. 제조 노하우가 담긴 공정 데이터가 외부 서버에 올라가는 구조입니다. Needle2는 기계 옆에서, 외부 전송 없이 처리합니다.

### ③ 창고·물류 현장의 메모 자동 정리

현장 직원이 메모한 "박스 12개 입고, 파손 2개, 3번 선반" 같은 비정형 텍스트를 Needle2가 자동으로 구조화합니다. 날짜·수량·위치·비고 항목이 정해진 형식(JSON)으로 나옵니다. 인터넷 없는 창고에서도 스마트폰 하나면 됩니다.

## 지금 당장 해보기 — 설치부터 첫 답변까지 4단계

준비물은 파이썬이 설치된 PC뿐입니다. 인터넷은 설치할 때만 잠깐 필요합니다.

![Needle2 설치·실행 흐름](/images/blog/needle2-offline-ai-14mb-guide-fig2.svg)
*▲ Needle2 설치·실행 흐름 · 출처: github.com/cactus-compute/needle*

**1단계 — 설치**

```bash
pip install cactus-needle
```

**2단계 — 파이썬 파일 작성**

아래 내용을 `test.py`로 저장합니다.

```python
from cactus_needle import Needle

model = Needle()
response = model.generate(
    "다음 메모를 JSON으로 정리해줘: 박스 12개 입고, 파손 2개, 3번 선반 배치."
)
print(response)
```

**3단계 — 실행**

```bash
python test.py
```

첫 실행 시 모델 파일(14MB)이 자동 다운로드됩니다. 이후엔 오프라인에서 바로 실행됩니다.

**4단계 — 오프라인 테스트**

와이파이를 끊고 다시 실행합니다. 똑같이 돌아갑니다. 이제 인터넷 없이 AI가 작동하는 겁니다.

## 자주 묻는 질문 (FAQ)

**Q. 한국어로도 답변이 나오나요?**

A. 한국어 입력과 출력이 가능합니다. 다만 Needle2는 영어 중심으로 학습된 모델이라, 영어에 비해 한국어 답변 품질이 다소 낮을 수 있습니다. 간단한 분류·정리 업무는 한국어로도 무리 없이 사용할 수 있습니다.

**Q. 스마트폰에 직접 올릴 수 있나요?**

A. 공식 GitHub에서 안드로이드 스마트폰 동작을 확인하고 있습니다. 구체적인 스마트폰 설치 방법은 [github.com/cactus-compute/needle](https://github.com/cactus-compute/needle) README를 참고하세요. PC에서 먼저 테스트해보는 것이 시작하기 가장 편합니다.

**Q. 라즈베리파이 말고 기존 PC를 써도 되나요?**

A. 됩니다. 파이썬이 설치된 일반 Windows·Mac PC에서도 동일하게 실행됩니다. 현장 상시 운영용으로는 전력 소모가 적은 라즈베리파이나 소형 PC가 적합합니다.
