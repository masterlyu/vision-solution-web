청주에서 반려동물 간식 스마트스토어를 하는 B씨(43세, 이해를 돕기 위한 가상 사례)는 매주 월요일 아침이 괴롭습니다. 지난주 주문 엑셀을 열고, 후기 40개를 읽고, 상세페이지 문구까지 고치다 보면 오전이 사라집니다. 직원은 한 명뿐이에요.

그런데 GitHub 인기 흐름을 매일 기록하는 일본 사이트 Ageshio의 순위에서, 10월 27일 16위였던 앱이 11월 2일 5위까지 올라왔습니다. **Orkas**예요. 목표를 말하면 AI 직원 여러 명이 나눠서 일하는 앱이에요. 무료인 데다 소스까지 공개돼 있고요.

솔깃하죠. 하지만 설치 전에 짚을 게 있습니다.

![center](/mascot/md/emotion/cat_thinking.png)

## AI 직원 16명과 팀장 한 명

Orkas는 쉽게 말하면 AI 팀장이 일을 쪼개 직원에게 나눠 주는 앱입니다. 팀장 역할은 'Commander'가 맡아요. 사장님이 목표를 말하면 할 일 목록으로 나누고, 알맞은 직원에게 배분합니다.

공식 저장소 설명에 따르면 직원은 16명이 기본으로 들어 있습니다. 리서치, 글쓰기, 영상, 화면 디자인, 오피스 문서, 쇼핑몰 운영이 그 분야예요. Claude Code나 Codex처럼 이미 쓰는 AI 도구도 같은 팀에 불러올 수 있습니다.

라이선스는 MIT입니다. 회사에서 써도 되고 소스도 직접 읽을 수 있어요.

### '로컬 우선'이 '내 컴퓨터에서만'은 아닙니다

여기가 첫 번째 확인 사항입니다. 소개 글마다 "데이터는 내 컴퓨터에"라고 쓰여 있어서, AI까지 내 PC 안에서 돌아간다고 오해하기 쉬워요.

공식 FAQ는 분명히 선을 긋습니다. Orkas는 로컬 LLM이 아니고, 사용자가 고른 모델을 불러다 쓰는 앱이라는 겁니다. 대화 기록과 파일은 기본적으로 내 디스크에 남아요. 질문 내용은 내가 고른 모델이나 엔드포인트로 전달됩니다.

어디로 가는지는 선택에 따라 갈립니다.

- 내 API 키를 쓰면 요청이 내 컴퓨터에서 모델 회사로 곧장 갑니다.
- 기본 제공 모델을 쓰면 Orkas의 관리형 서비스를 거칩니다.
- 로컬 모델 엔드포인트를 연결하면 그 경계 안에서 동작할 수 있어요. 소스 실행 방식은 로컬 모델과 함께 오프라인도 가능합니다.

바로 옆에 하나 더 알아 두세요. 설치형 앱에서 클라우드 동기화나 공유 프로젝트를 켜면, 선택한 데이터는 Orkas 서버에 저장됩니다. 그래서 고객 개인정보가 든 파일은 어느 방식으로든 올리지 않는 게 안전합니다.

## 설치 전 확인할 현실 조건

두 번째 확인 사항은 조건과 비용입니다. 공식 문서 기준으로 정리하면 이렇습니다.

| 구분 | 설치형 앱 | 소스 직접 실행 |
|---|---|---|
| 운영체제 | macOS 12 이상, Windows 10 이상 | macOS, Windows, Linux |
| 계정 | 로그인 필요, 500 크레딧 무료 | 계정 불필요 |
| 모델 | 기본 모델 또는 내 API 키 | 내 API 키 또는 로컬 모델 |
| 준비물 | 설치 파일만 | Node 22.12 이상, 첫 실행 때 구성요소 자동 내려받기 |
| 오프라인 | 불가 | 로컬 모델과 함께 쓰면 가능 |

무료 크레딧 500을 다 쓰면 어떻게 될까요? 비용과 한계를 따로 모으면 이렇습니다.

| 항목 | 비용 | 한계·주의 |
|---|---|---|
| 앱 자체 | 무료 (MIT 오픈소스) | 설치형은 로그인 필요, 오프라인 불가 |
| 제공 모델 | 시작 시 500 크레딧 무료 | 다 쓰면 크레딧 구매, 유료 플랜, 내 API 키 연결 중 하나를 골라야 함 |
| 내 API 키 연결 | Orkas는 수수료를 붙이지 않음 | 모델 회사 사용료는 별도, 쓴 만큼 나감 |
| 유료 플랜 (2026-11-03 [공식 가격 페이지](https://orkas.ai/pricing/) 기준) | Free: $0, 평생 500 크레딧 / Lite: 월 $5.99, 월 1,000 크레딧 / Pro: 월 $16.99, 월 5,000 크레딧 / Max: 월 $29.99, 월 10,000 크레딧 | 가격은 바뀔 수 있으니 가입 전에 [가격 페이지](https://orkas.ai/pricing/)에서 다시 확인. 일부 문서(README)에는 월 $11.99부터라고 적혀 있어 가격 페이지와 다름. 이 글은 가격 페이지 기준 |
| 로컬 모델 | 공식 문서에 Orkas 측 비용 안내 없음 | 최소 RAM·GPU 사양은 공식 문서에 공개돼 있지 않음. 로컬 모델은 그 모델 자체의 사양이 따로 필요 |

솔직한 단점도 있습니다. 컴퓨터가 꺼져 있으면 자동 실행도 멈춥니다. 공식 FAQ가 직접 인정하는 부분이에요. 다만 1.9 버전부터는 놓친 가장 최근 1회를 컴퓨터를 켠 뒤 12시간 안에 따라잡는다고 합니다. 내장 직원의 결과물이 우리 가게 기준에 맞는지는 직접 써 봐야 압니다. 그래서 무료 크레딧으로 한 주쯤 시험해 보시는 걸 권합니다.

반대로 장점도 있어요. 챗봇 하나에 일을 계속 설명하는 대신, 프로젝트에 규칙과 자료를 저장해 두고 다음 대화에서 이어 갈 수 있어요.

그렇다면 B씨의 한 주는 어떻게 바뀔까요?

## B씨의 주간 업무 자동화

세 번째 확인 사항은 내 자료를 어디까지 맡길지입니다. B씨는 이렇게 설정했습니다.

먼저 스토어 매뉴얼과 상품 설명 PDF를 앱의 '라이브러리'에 넣었습니다. 문서를 조각내 내 컴퓨터에 색인을 만들고, 답할 때 출처 문단을 함께 보여 주는 기능이에요. 색인용 모델도 내 컴퓨터에서 돌아갑니다.

다음으로 주문·매출 엑셀을 내려받아 쇼핑몰 분석 직원에게 읽혔습니다. 후기가 나쁜 이유와 환불이 몰린 상품을 요약해 주는 일이에요. 마지막으로 이 작업을 주 단위 반복으로 예약했어요. 앱의 예약 기능은 시간·일·주·월 단위로 반복할 수 있습니다.

앱은 Gmail, 구글 시트, 노션 같은 서비스와도 연결됩니다. 기본 설정에서는 메일 발송, 게시, 삭제 전에 먼저 물어봐요. B씨는 이 기본 설정을 그대로 뒀습니다. 고객에게 나가는 답장을 AI가 멋대로 보내면 곤란하니까요.

여기까지는 사장님이 직접 해볼 수 있습니다. 연결 목록에 없는 사내 자체 프로그램(주문 시스템이나 ERP 등)과 이어 붙이는 단계부터는 개발이 필요할 수 있어요. 그 부분은 따로 상담이 필요합니다.

![center](/mascot/md/service/cat_svc_ai.png)

### 비젼솔루션은 이렇게 봅니다

AI 앱이 쏟아질수록 중요한 질문은 "무엇을 시킬까"가 아니라 "무엇을 맡기지 않을까"입니다. 도구가 좋아질수록 맡기는 범위는 저절로 넓어지거든요. 범위를 정하는 건 끝까지 사람 몫입니다.

작은 회사일수록 이 선이 곧 신뢰입니다. 고객 정보는 맡기지 않고, 발송은 사람이 누르는 것. 이 두 줄만 지켜도 AI 팀은 든든한 직원이 됩니다.

![에이전트 열풍에 대한 카파시의 말](/images/blog/orkas-free-ai-team-desktop-sme-guide-fig2.svg)
*▲ 안드레이 카파시, 2025년 10월 Dwarkesh Patel 인터뷰 (번역) · 출처: dwarkesh.com/p/andrej-karpathy*

OpenAI 창립 멤버 출신인 카파시도 비슷하게 말했습니다. 업계에 과대 예측이 있고, 에이전트는 앞으로 10년에 걸쳐 다듬어질 기술이라는 겁니다. 지금 앱이 완벽하지 않아도 이상한 일이 아니에요.

## 따라 하기 5단계

![Orkas 시작 3단계](/images/blog/orkas-free-ai-team-desktop-sme-guide-fig3.svg)
*▲ 시작 순서 요약 · 출처: github.com/Orkas-AI/Orkas*

1. 공식 저장소부터 확인하세요. 주소는 `https://github.com/Orkas-AI/Orkas`입니다. 검색하면 이름이 같은 저장소가 많이 나옵니다. 공식 저장소를 복제한 포크가 480개나 되고, 이름만 같은 전혀 다른 프로젝트도 있어요. 설치 파일은 공식 저장소 첫 화면의 다운로드 링크로만 받으세요.
2. 설치 후 새 프로젝트를 만드세요. 프로젝트에는 목표와 규칙을 적습니다. 아래 문장을 그대로 붙여 넣어 보세요.

   `우리는 반려동물 간식 온라인 스토어입니다. 말투는 정중하고 따뜻하게. 고객 이름과 연락처는 절대 다루지 않습니다. 메일 발송과 게시는 내가 확인하기 전에는 하지 않습니다.`

3. 라이브러리에 자료를 넣으세요. 개인정보가 없는 상품 설명서나 응대 매뉴얼부터 올립니다. 주문 엑셀은 이름·연락처 열을 지운 사본으로 쓰세요.
4. 첫 일을 시켜 보세요.

   `첨부한 지난주 주문 파일을 읽고, 환불이 많은 상품 3개와 이유를 표로 정리해 줘. 근거가 된 행 번호도 같이 보여 줘.`

5. 결과가 믿을 만하면 예약하세요. 같은 지시를 주 단위 반복으로 예약합니다. 요일과 시간은 예약 화면에서 정하세요. 컴퓨터를 켜 두는 날에만 돈다는 점은 기억해 두세요.

회사 PC에 설치하기가 부담스러우면, 사내에서 쓰는 AI 채팅부터 시작하는 방법도 있어요. [Open WebUI로 사내 AI 채팅 만들기](/blog/openwebui-private-team-ai-chat-free-sme-guide)를 참고하세요.

## 자주 묻는 질문

### API 키 없이도 쓸 수 있나요?

설치형 앱은 가능합니다. 시작할 때 500 크레딧이 들어오고, 소진 후에는 결제하거나 내 키를 연결하면 됩니다.

### 내 컴퓨터 안에서만 AI를 돌릴 수 있나요?

소스 실행 방식에 로컬 모델 주소를 연결하면 오프라인으로 돌릴 수 있습니다. 다만 모델 설치와 설정은 어느 정도 개발 지식이 필요해요.

### 직원 몇 명이 같이 쓸 수 있나요?

공유 프로젝트는 설치형 앱에만 있고, 공개 소스 버전에는 아직 없습니다.

자동화가 막혀서 시간이 없거나 기존 시스템과 연결이 필요하다면 [무료 상담](/contact)으로 편하게 물어보세요.

이 글이 도움이 되셨나요? AI 궁금해하는 분 계시면 공유해 주세요. 댓글로 질문하시면 성심껏 답변드릴게요!
