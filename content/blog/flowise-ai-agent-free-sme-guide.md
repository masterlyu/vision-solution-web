**Flowise 장단점 비교**

장점은 코딩 없이 화면에서 블록 연결만으로 에이전트 구성이 가능하다는 점입니다. 로컬(내 PC)에서 실행할 수 있어서 데이터가 외부로 나가지 않습니다. 단점은 Node.js 설치가 처음이라면 30분 정도 소요되고, 대규모 자동화에는 별도 서버가 필요할 수 있다는 점입니다.

## 지금 바로 따라해 보세요 — 설치 3단계

![Flowise 설치 3단계 흐름](/images/blog/flowise-ai-agent-free-sme-guide-fig2.svg)
*▲ Flowise 설치 흐름 · 출처: Flowise 공식 문서(flowiseai.com)*

**1단계: Node.js 설치**

[nodejs.org](https://nodejs.org)에 접속해 LTS 버전을 내려받습니다. 설치 파일을 실행한 뒤 '다음'만 눌러주시면 됩니다.

**2단계: Flowise 실행**

Windows는 명령 프롬프트(cmd), Mac·Linux는 터미널을 열고 아래 명령어를 입력합니다.

```bash
npx flowise start
```

처음 실행 시 파일을 자동으로 내려받습니다. 2~3분 정도 걸립니다.

**3단계: 브라우저 접속**

터미널에 `Server started at port 3000` 메시지가 나오면, 브라우저 주소창에 입력합니다.

```
http://localhost:3000
```

드래그앤드롭 화면이 열립니다. 이제 AI 에이전트를 만들 준비가 됐습니다.

## 우리 회사 업무에 붙이는 2가지 시나리오

**시나리오 1 — 반복 문의 자동 응대**

카페·소매점을 운영하신다면 하루에도 비슷한 문의가 수십 번 반복됩니다. "주차 되나요?", "영업시간이 어떻게 되나요?" 같은 질문입니다.

Flowise에서 ChatGPT 노드를 연결하고, FAQ 내용을 텍스트 파일로 저장해 연결합니다. 에이전트가 이 파일을 읽고 자동으로 답변합니다. 설정 시간은 약 30분입니다.

**시나리오 2 — 견적서 초안 자동 작성**

Flowise에 엑셀 가격표를 연결합니다. 고객 요청 사항을 입력하면 에이전트가 가격표를 참고해 견적서 초안을 만들어줍니다. 담당자는 검토·수정만 하면 됩니다. 견적 작성 시간이 30분에서 5분으로 줄어드는 효과를 기대할 수 있습니다.

기본 체험까지는 직접 해보실 수 있습니다. 그 이상의 맞춤 자동화—회사 시스템 연동, 대화형 챗봇 구축—가 필요하시면 문의해 주시면 됩니다.

**Q. ChatGPT 계정 없어도 되나요?**  
Flowise 자체는 무료이고 계정도 필요 없습니다. AI 모델(ChatGPT, Claude 등)을 연결할 때는 해당 서비스의 API 키가 필요합니다.
