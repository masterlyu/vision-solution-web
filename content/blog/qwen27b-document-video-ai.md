계약서 더미가 쌓여 있습니다. 법무팀이 없는 회사에서는 대표님이나 담당자가 직접 읽어야 합니다. 불리한 조항이 어디 숨어 있는지, 배상 범위가 어디까지인지 — 한 장 한 장 넘기면서요.

그 계약서 전부를 AI에 통째로 던지고 "공급사에 불리한 조항 찾아줘"라고 말하면 어떨까요? 이번 주 그게 현실이 됐습니다.

지난 8월 14일, 알리바바 Qwen팀이 [Qwen 3.8 27B](https://huggingface.co/Qwen/Qwen3.8-27B)를 무료로 공개했습니다. Apache 2.0 라이선스라 상업적으로 써도 됩니다. 구독료 없이 내 컴퓨터 안에서만 돌아갑니다.

> **지금 바로 5분 실습:** [실습 가이드 바로가기](#ollama로-5분-설치--내-pc에서-직접-돌린다)로 내려가세요. Ollama 명령어 한 줄이면 됩니다.

## 계약서 몇 페이지나 읽어주나요?

![center](/mascot/md/emotion/cat_happy.png)

AI가 "한 번에 읽을 수 있는 분량"을 컨텍스트 창이라고 합니다. 쉽게 말하면 AI의 단기 기억 용량이죠. 이게 클수록 긴 문서도 통째로 처리할 수 있습니다.

Qwen 3.8 27B의 컨텍스트 창은 262,144 토큰입니다. A4 기준 약 300~350페이지 분량입니다. 표준 납품 계약서 한 건이 보통 20~30페이지니까, 계약서 10건을 한꺼번에 올려도 AI가 전부 읽습니다.

텍스트만 읽는 게 아닙니다. 이미지와 영상도 함께 분석합니다. 회의 녹화 영상을 올리면 발언 내용을 요약하고, 결정 사항만 추려줍니다.

![Qwen 3.8 27B 핵심 스펙](/images/blog/qwen27b-document-video-ai-fig1.svg)
*▲ Qwen 3.8 27B 핵심 스펙 · 출처: HuggingFace Qwen 모델 카드*

HuggingFace에서 큰 주목을 받았습니다. 오픈소스 AI 커뮤니티가 이렇게 빠르게 반응한 이유는 단순합니다. 이 규모의 컨텍스트를 무료로 쓸 수 있는 모델이 없었거든요.

## Ollama로 5분 설치 — 내 PC에서 직접 돌린다

![center](/mascot/md/emotion/cat_thinking.png)

"로컬 AI"란 외부 서버 대신 내 컴퓨터에서 직접 돌아가는 AI입니다. 외부로 데이터가 나가지 않으니, 계약서·매뉴얼·인사 서류 같은 기밀 문서를 올려도 새지 않습니다.

설치 도구는 **Ollama**입니다. 무료 오픈소스 도구로, 터미널 명령어 한 줄로 AI 모델을 다운로드하고 실행합니다. 복잡한 서버 설정이 필요 없습니다.

### 어떤 컴퓨터가 필요한가요?

Qwen 3.8 27B는 270억 개의 변수(파라미터)를 가진 모델입니다. 숫자가 클수록 더 정확하지만, 그만큼 컴퓨터 사양이 필요합니다.

| 구분 | 필요 사양 | 참고 |
|------|----------|------|
| NVIDIA GPU | VRAM 18GB 이상 | RTX 3090·4090·A4000 24GB 등 |
| Apple Silicon Mac | 통합 메모리 24GB 이상 | M2 Max·M3 Pro·M4 Pro 이상 |
| CPU만 사용 (GPU 없음) | RAM 64GB 이상 | 동작하나 속도 매우 느림 |

RTX 3090(24GB)이 중고 시장에 100만 원대에 나옵니다. M3 Pro MacBook이 190만 원대(18GB)부터 시작합니다. 일반 사무용 PC(내장 그래픽·RAM 16~32GB)라면 아직은 어렵습니다.

> **사양이 부족하다면?** 더 가벼운 7B 모델(`ollama run qwen3.8:7b`)은 VRAM 6~8GB면 동작합니다. 정확도는 조금 낮지만 간단한 문서 요약에는 충분합니다.

### 클라우드 유료 AI와 어떻게 다른가요?

솔직히 비교해봤습니다.

| 항목 | Qwen 3.8 27B (로컬) | ChatGPT·Claude 유료 플랜 |
|---|---|---|
| 월 비용 | 0원 (전기료 별도) | 월 20~25달러 |
| 데이터 보안 | 외부 전송 없음 ✅ | 제공사 서버로 전송 |
| 컨텍스트 창 | 262,144 토큰 ✅ | 서비스별 상이 |
| 속도 | GPU 사양에 따라 다름 | 빠름 |
| 설치 난이도 | 명령어 3줄 | 회원가입만 |
| 오프라인 사용 | 가능 ✅ | 인터넷 필요 |

기밀 문서를 다루는 중소기업이라면 로컬 실행이 더 안전합니다. 클라우드 AI는 데이터가 외부 서버로 나가는 구조입니다. 그 서버가 어떤 나라에 있는지, 데이터가 어떻게 처리되는지는 약관에 쓰여 있지만 보통 읽지 않죠.

### 설치 5단계

![Ollama 설치·실행 3단계 흐름](/images/blog/qwen27b-document-video-ai-fig2.svg)
*▲ Ollama로 Qwen 3.8 27B 설치 흐름 · 출처: Ollama 공식 문서*

**1단계 — Ollama 설치**

[ollama.com](https://ollama.com)에서 운영체제에 맞는 설치 파일을 내려받아 실행합니다. Windows·Mac·Linux 모두 지원합니다.

**2단계 — 터미널 열기**

Windows: 시작 버튼 → "cmd" 검색 → 명령 프롬프트 실행
Mac: Cmd+Space → "터미널" 검색 → 실행

**3단계 — 모델 다운로드 및 실행**

아래 명령어를 복사해 붙여넣으면 모델이 자동 다운로드되고 바로 실행됩니다.
모델 파일이 약 18GB이므로 인터넷 속도에 따라 10~30분이 걸릴 수 있습니다.

```bash
ollama run qwen3.8:27b
```

**4단계 — 계약서 분석 프롬프트 예시**

모델이 실행되면 `>>>` 프롬프트가 나타납니다. 아래 텍스트를 복사한 뒤, 대괄호 부분에 계약서 내용을 붙여넣으세요.

```
다음 계약서를 읽고 공급업체에 불리한 조항이 있으면 알려주세요.
특히 지체 배상금, 품질 보증 기간, 손해배상 한도 조항을 중심으로 검토해주세요.

[계약서 전문을 여기 붙여넣기]
```

**5단계 — 회의 영상 요약 프롬프트 예시**

```
이 회의에서 결정된 사항과 각 항목의 담당자·기한을 정리해줘.

[회의 녹음 텍스트 또는 자막 파일 내용 붙여넣기]
```

영상 파일 자체를 직접 넣으려면 Whisper 같은 음성인식 도구로 텍스트로 먼저 변환한 뒤 Qwen에 올리는 방법이 가장 안정적입니다.

## 중소기업 적용 시나리오 2가지

중소기업이 실제로 어떻게 쓸 수 있는지, 구체적인 업무 상황을 그려봤습니다.

---

**시나리오 1 — 납품 계약서 검토 (제조·유통업)**

부품 납품 계약서 30페이지를 AI에 올립니다. "지체 배상금 조항이 공급사에 불리하게 작성됐는지, 품질 책임 범위가 어디까지인지 알려줘"라고 하면 30초 안에 요약이 나옵니다.

AI가 조항별 리스크를 먼저 걸러주면, 담당자는 AI가 표시한 부분만 직접 확인하면 됩니다. 처음부터 끝까지 읽던 방식과 비교하면 검토 시간이 크게 줄어듭니다. 물론 최종 판단은 사람이 합니다 — AI는 어디를 봐야 하는지 알려주는 역할입니다.

---

**시나리오 2 — 주간 회의 요약 (서비스업·소매업)**

1시간 회의를 녹음한 뒤 Whisper로 텍스트 변환, 그 내용을 Qwen에 붙여넣습니다. "이번 주 실행 과제와 담당자·기한만 정리해줘"라는 요청 하나로 액션 아이템 목록이 완성됩니다.

참석 못 한 직원도 5분 안에 핵심만 파악합니다. 회의록을 별도로 작성하는 시간이 없어집니다.

---

## (주)비젼솔루션의 시각

기업 규모가 작을수록 AI 도입의 이유가 두 가지로 좁혀집니다. "돈이 없어서"와 "데이터를 남에게 주기 싫어서."

공개 AI 서비스는 데이터를 외부 서버로 보냅니다. 그 서버가 어떤 나라에 있는지, 데이터를 어떻게 처리하는지는 약관에 묻혀 있습니다. 반면 내 컴퓨터에서 돌아가는 AI는 데이터가 밖으로 나가지 않습니다.

알리바바가 이번 주 무료로 공개한 Qwen 3.8 27B는 중소기업이 데이터 주권을 갖고 AI를 쓸 수 있는 현실적 선택지가 됐습니다. 진입 장벽은 GPU 사양이지만, 이 장벽은 해마다 낮아지고 있습니다. 지금 익혀두면 6개월 뒤 속도가 달라집니다.

## 자주 묻는 질문

**Q. 한국어를 잘 이해하나요?**

네, 잘 이해합니다. Qwen 시리즈는 중국어 기반이지만 한국어·영어도 높은 수준으로 지원합니다. 한국어 계약서와 회의 내용 모두 자연스럽게 처리합니다.

**Q. 일반 사무용 PC(RAM 16GB, 내장 그래픽)에서도 되나요?**

Qwen 3.8 27B는 어렵습니다. 더 가벼운 7B 모델(`ollama run qwen3.8:7b`)은 RAM 16GB 환경에서도 시도해볼 수 있습니다. 속도가 느리고 정확도가 낮지만, 간단한 문서 요약에는 충분할 수 있습니다.

**Q. 회사 서버에 설치해서 여러 직원이 함께 쓸 수 있나요?**

가능합니다. Ollama는 API 서버 모드를 지원해서, 사내 서버에 설치하면 여러 PC에서 동시 접근할 수 있습니다. 서버 설정이 필요하므로 IT 담당자나 전문 업체의 도움을 받는 게 좋습니다.

**Q. 계약서 분석 결과를 그대로 믿어도 되나요?**

보조 도구로 쓰시기 바랍니다. AI가 빠르게 위험 조항 후보를 추려주면, 담당자가 그 부분만 직접 확인하는 방식이 현실적입니다. 중요한 계약은 반드시 전문가 검토가 필요합니다.
