거래처 견적 메일, 주문 확인 후 엑셀 업데이트, 주간 보고서 복사-붙여넣기. 담당자가 이 작업 하나하나에 20~30분씩 씁니다. 미국 중소기업 단체 SCORE의 2025년 조사에 따르면, 5~25명 규모 회사의 경영자와 직원은 **한 주에 15~25시간**을 자동화 가능한 반복 업무에 씁니다. "이 사람만 할 수 있다"는 이유로 아무도 손대지 못하는 그 업무, 이번 주부터 달라질 수 있습니다.

## AI 에이전트, 쉽게 말하면

**AI 에이전트**란 "사람 대신 컴퓨터가 여러 작업을 순서대로 자동 처리하는 것"입니다. 예를 들어 이렇게 동작합니다.

> 주문 메일 도착 → 품목·수량 자동 추출 → 재고 엑셀에 자동 입력 → 담당자에게 카카오톡 알림 전송

사람이 할 때는 창을 옮겨 다니고, 복사-붙여넣기를 반복해야 합니다. AI 에이전트는 이 과정을 24시간 멈추지 않고 혼자 처리합니다.

OpenAI의 발표는 이 기능을 기업 수준으로 올린 것입니다. 그런데 비용이 문제입니다. OpenAI API는 사용량에 따라 과금되고, 작은 회사에서 매달 수만 건을 처리하면 요금이 만만치 않습니다.

그래서 소개할 도구가 **n8n**입니다.

---

## n8n — 코딩 없이, 무료로, 내 서버에

**n8n**(읽을 때: 'nodemation')은 레고 블록처럼 앱과 앱을 연결해 자동화 흐름을 만드는 오픈소스 플랫폼입니다. GitHub에 **204,000개 이상의 별**을 받았고, Gmail·Slack·엑셀·MySQL·카카오워크 등 **400개 이상의 앱**을 코딩 없이 연결할 수 있습니다.

가장 큰 특징은 **무료 셀프호스팅**입니다. 회사 서버나 저렴한 클라우드 인스턴스에 직접 설치하면 사용량에 관계없이 무료입니다.

![center](/mascot/md/emotion/cat_thinking.png)

### n8n vs 다른 선택지

| 비교 항목 | n8n (셀프호스팅) | Zapier (클라우드) | Make (클라우드) |
|---|---|---|---|
| 비용 | **무료** (서버비 별도) | 월 2만원~(작업 수 제한) | 월 1만원~(작업 수 제한) |
| 데이터 위치 | **내 서버** | 미국 서버 | 미국 서버 |
| AI 노드 내장 | ✅ | 제한적 | 제한적 |
| 설치 난이도 | 중간 (Docker 필요) | 쉬움 | 쉬움 |
| 월 작업 한도 | **무제한** | 750건~ 제한 | 1,000건~ 제한 |

**단점도 솔직히 말씀드립니다.** 셀프호스팅은 서버 관리가 필요합니다. 설치 자체는 Docker 명령 한 줄이지만, SSL 설정·보안 패치는 직접 해야 합니다. 서버 관리가 부담이라면 n8n 클라우드 플랜($20/월~)도 있으니 그 옵션도 고려해 보세요.

### 최소 사양

| 항목 | 최소 | 권장 |
|---|---|---|
| RAM | 2GB | 4GB |
| 저장공간 | 20GB | 40GB |
| 운영체제 | Ubuntu 22.04 | Ubuntu 22.04 |

월 2~3만원짜리 저렴한 클라우드 서버(AWS Lightsail, Oracle 무료 티어 등)로도 충분합니다.

## 중소기업에서 실제 쓰는 방법

### 시나리오 A: 견적 메일 자동 발송

거래처에서 문의 메일이 오면 → n8n이 내용을 분석하고 → 견적 템플릿에 자동 입력 → PDF로 변환해 자동 회신합니다. 건당 20분 걸리던 작업이 0분이 됩니다.

### 시나리오 B: 주문 재고 자동 관리

쇼핑몰 주문 발생 → 재고 엑셀에 자동 차감 → 기준 수량 이하 시 담당자에게 문자 발송. 까먹으면 안 되는 일을 n8n이 대신 챙깁니다.

### 시나리오 C: 주간 보고서 자동 생성

매주 월요일 오전 9시 → 지난주 판매 데이터 자동 수집 → 보고서 형식으로 정리 → 대표님 이메일로 자동 발송. 월요일 아침 보고서 준비 시간이 사라집니다.

## (주)비젼솔루션의 관점

자동화 도구는 "회사를 스마트하게 만들어주는 마법"이 아닙니다. **업무 규칙을 눈에 보이는 흐름으로 저장하는 방법**입니다. n8n 워크플로 하나는 "A가 생기면 B를 해라"는 사내 규칙을 그림으로 기록한 겁니다. 사람이 그 규칙을 머릿속에만 담고 있다면 퇴사와 함께 사라집니다. n8n에 저장하면 회사 자산이 됩니다. 도구의 가치는 기능이 아니라, 그 안에 담긴 업무 지식의 양입니다.

## 5단계 실습 — 지금 바로 시작하기

Docker가 설치된 서버 또는 PC에서 바로 시작할 수 있습니다.

![center](/mascot/md/emotion/cat_surprised.png)

### 1단계: Docker 설치 확인

```bash
docker --version
```

출력이 안 된다면 [Docker 공식 사이트](https://docs.docker.com/get-docker/)에서 무료로 설치하세요.

### 2단계: n8n 실행 (명령 1줄)

```bash
docker run -it --rm \
  --name n8n \
  -p 5678:5678 \
  -v ~/.n8n:/home/node/.n8n \
  n8nio/n8n
```

### 3단계: 브라우저에서 접속

브라우저에서 `http://localhost:5678` 접속. 처음에는 계정 설정 화면이 나타납니다.

### 4단계: 첫 번째 워크플로 만들기

**트리거 노드 추가** → "Schedule Trigger" 선택 (매일 오전 9시 등 시간 지정)  
→ **다음 노드 추가** → Gmail, Slack, 엑셀 등 원하는 앱 연결  
→ 오른쪽 상단 **"Activate"** 클릭

### 5단계: 업무 데이터 연결

연동할 앱의 계정 인증을 추가합니다. Gmail은 구글 계정 연동, Slack은 워크스페이스 연동으로 5분 내 완료됩니다.

## 더 깊이 활용하려면

기본 설치까지는 위 5단계로 가능합니다. 실제 업무에 붙이려면 한 단계가 더 있습니다.

- **회사 데이터 연결**: 기존 MySQL, 구글 드라이브, 카카오워크 API 연동
- **AI 노드 추가**: GPT-4o Mini를 n8n에 연결해 메일 내용 자동 분류·요약
- **외부 접근 설정**: SSL 인증서와 도메인 연결로 어디서나 관리
