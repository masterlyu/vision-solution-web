오전 9시. 경쟁사 쇼핑몰을 열어 우리 상품과 가격을 비교합니다. 상품 10개, 비교 사이트 3곳이면 30번의 클릭입니다. 기록하고, 다음 사이트를 열고, 또 클릭합니다. 어제도, 그제도 똑같이 하셨을 겁니다.

2026년 9월 3일, OpenAI가 GPT-6 Astra를 공개했습니다. 핵심은 **'컴퓨터 사용(Computer Use)'** 기능입니다. AI가 직접 웹사이트를 열고, 버튼을 누르고, 폼을 채웁니다. 사용자는 말로 지시만 하면 됩니다. ChatGPT Plus·Business 이용자라면 지금 바로 쓸 수 있습니다.

> **지금 바로 시작해 보세요**: [chatgpt.com](https://chatgpt.com/) 접속 → 모델 선택에서 GPT-6 Astra 선택 → "○○ 사이트에서 [상품명] 가격을 찾아줘" 입력

## '컴퓨터 사용'이 뭔지, 쉽게 말하면

![center](/mascot/md/emotion/cat_happy.png)

지금까지 AI는 "알려주기"만 했습니다. "경쟁사 가격을 어디서 보면 되나요?" 하고 물으면 방법을 설명해 줬습니다. 직접 찾아주진 못했습니다.

GPT-6 Astra의 '컴퓨터 사용'은 다릅니다. AI가 **실제로 브라우저를 열고, 검색하고, 클릭하고, 결과를 가져옵니다.** 마치 옆자리 막내 직원에게 "○○몰에서 이 제품 가격 찾아줘"라고 시키면 직접 들어가서 화면을 보고 돌아오는 것처럼요.

한 줄 정의를 드리면 이렇습니다. **'컴퓨터 사용'이란 AI가 마우스와 키보드를 대신 조작해 실제 작업을 완료하는 기능입니다.** 결과물이 설명이 아니라 실제로 처리된 업무라는 게 핵심입니다.

| 구분 | 기존 ChatGPT | GPT-6 Astra '컴퓨터 사용' |
|------|-------------|------------------------|
| 하는 일 | 방법 알려주기 | 직접 실행 |
| 결과물 | 텍스트 설명 | 완료된 작업 |
| 사용자 할 일 | 직접 실행 | 말로 지시만 |

## ChatGPT에서 직접 쓰는 법

![center](/mascot/md/emotion/cat_thinking.png)

ChatGPT Plus 또는 Business 요금제에 가입되어 있으면 추가 설치 없이 바로 사용할 수 있습니다.

**사용 순서:**

1. [chatgpt.com](https://chatgpt.com/)에 접속합니다
2. 채팅 상단 모델 선택에서 **GPT-6 Astra**를 선택합니다
3. 원하는 작업을 자연어로 입력합니다

**바로 복붙할 수 있는 프롬프트 예시:**

```
"[사이트 URL]에 들어가서 [상품명]의 현재 판매가격을 알려줘"

"[거래처 홈페이지]의 공지사항에서 납기·배송 관련 내용을 모두 정리해줘"

"네이버쇼핑에서 [우리 제품명]을 검색해서 최저가 판매처 3곳을 표로 만들어줘"
```

그러면 실망스러운 얘기도 솔직하게 드려야 합니다. 2026년 9월 현재 몇 가지 제약이 있습니다.

- **로그인이 필요한 사이트**: 아이디·비밀번호를 AI에게 직접 알려줘야 합니다. 민감한 계정 정보는 신중하게 판단하세요
- **오류 가능성**: 작업이 복잡할수록 오류율이 높아집니다. 발주·결제처럼 되돌리기 어려운 업무는 AI가 처리한 뒤 반드시 사람이 검토해야 합니다
- **대량 반복은 한계**: 수십 건 이상 반복 작업은 전용 자동화 도구가 더 안정적입니다

## 우리 회사에 어떻게 쓰나 — 반복 클릭 업무 3가지

중소기업에서 바로 적용할 수 있는 시나리오 세 가지입니다.

**① 경쟁사 가격 모니터링**

도입 전에는 담당자가 매일 아침 쇼핑몰 3~4곳을 직접 돌아다니며 상품별 가격을 엑셀에 기록했습니다. 사이트마다 화면 구조가 달라 자동화도 어려웠습니다.

도입 후에는 "○○몰, △△마켓에서 [상품명] 판매가를 각각 알려줘"라고 입력합니다. AI가 사이트에 직접 들어가 확인하고 표로 정리해 줍니다. 직접 클릭하는 시간이 필요 없어집니다.

**② 거래처 재고·납기 조회**

여러 거래처 홈페이지에서 특정 부품의 재고 상황을 확인하는 일이 있습니다. 거래처마다 사이트 구조가 달라 자동화 스크립트 만들기가 쉽지 않습니다. GPT-6 Astra는 화면을 직접 '보고' 처리하기 때문에 사이트 구조에 상관없이 작동합니다.

**③ 반복 폼 입력**

매주 같은 형식의 발주서나 입고 확인서를 사이트에 직접 입력하는 업무입니다. 엑셀 파일이나 내용을 붙여 넣고 "이 내용으로 [사이트 URL]의 주문 폼에 입력해줘"라고 하면 됩니다.

## 무료 오픈소스 대안 — OpenHands

![center](/mascot/md/emotion/cat_surprised.png)

ChatGPT 구독이 없거나, 보안 이유로 회사 내부 서버에서 같은 기능을 구현하고 싶다면 **OpenHands**가 있습니다.

- GitHub: [All-Hands-AI/OpenHands](https://github.com/All-Hands-AI/OpenHands)
- 라이선스: MIT (무료, 상업 이용 가능)
- GitHub 별 수: 8만 개 이상 (2026년 9월 기준)

GPT-6 Astra와 동일한 개념, 즉 'AI가 컴퓨터를 직접 조작하는' 기능을 제공하는 오픈소스 프레임워크입니다. Docker가 설치된 환경과 LLM API 키(OpenAI 또는 Anthropic)가 있으면 회사 내부 서버에서 직접 운영할 수 있습니다.

| 항목 | GPT-6 Astra | OpenHands |
|------|------------|-----------|
| 비용 | ChatGPT 유료 구독 필요 | 소프트웨어 무료 (API 비용 별도) |
| 설치 | 없음 (바로 사용) | Docker 설치 + 설정 필요 |
| 데이터 보안 | OpenAI 서버 경유 | 내부 서버에서 처리 가능 |
| 기술 필요도 | 없음 | Docker 기본 지식 필요 |
| 대량 자동화 | 제한적 | 확장 가능 |

**OpenHands가 더 나은 경우**: 거래처 로그인 정보·내부 발주 데이터처럼 민감한 정보를 다루거나, 대량 반복 작업을 안정적으로 처리해야 할 때입니다.

설치 방법은 [OpenHands GitHub 공식 문서](https://github.com/All-Hands-AI/OpenHands)의 README를 참고하세요. Docker 기본 명령어를 다룰 수 있다면 단계별로 따라 하실 수 있습니다.

## (주)비젼솔루션이 보는 시각

AI가 마우스를 잡는 시대가 됐습니다. 그런데 더 중요한 건 '무엇을 시킬지'입니다. 클릭이 자동화되어도 어느 사이트에서, 어떤 정보를, 왜 수집해야 하는지 판단은 여전히 사람이 합니다. 도구가 강력할수록 그 도구를 어디에 쓸지 결정하는 능력이 실질적인 경쟁력이 됩니다. 중소기업이 AI 도입을 시작하려면 기술 선택보다 '우리 회사의 반복 업무 목록 만들기'가 먼저입니다.

## 오늘 바로 해볼 수 있는 1분 실습

ChatGPT Plus 계정이 있다면 지금 바로 해보세요.

**실습 1 — 가격 확인 (1분)**

GPT-6 Astra를 선택하고 아래 프롬프트를 그대로 입력합니다. [우리 회사 주력 상품명]만 바꾸면 됩니다.

```
네이버쇼핑에서 "[우리 회사 주력 상품명]"을 검색해서
현재 가장 저렴한 판매자 3곳의 가격과 판매처 이름을 표로 정리해줘.
```

**실습 2 — 정보 수집 (3분)**

```
[거래처 홈페이지 URL]에 접속해서
현재 보이는 공지사항이나 납기 관련 내용을 전부 복사해서 요약해줘.
```

결과가 나오면 "이 정보를 엑셀에 붙여 넣을 수 있게 표 형태로 다시 정리해줘"를 추가로 요청해 보세요. 직접 클릭하며 찾던 업무가 말 몇 마디로 처리되는 경험을 하실 수 있습니다.

## 자주 묻는 질문

**Q. ChatGPT Plus가 없어도 쓸 수 있나요?**

GPT-6 Astra의 '컴퓨터 사용' 기능은 현재 ChatGPT Plus 또는 Business 요금제 가입자만 사용할 수 있습니다. 무료 계정에서는 지원되지 않습니다. 무료로 비슷한 기능을 원하신다면 앞서 소개한 OpenHands가 대안입니다.

**Q. AI가 실수로 잘못된 주문을 넣을 수도 있나요?**

있습니다. 현재 기술 수준에서 AI의 컴퓨터 조작은 완벽하지 않습니다. 발주·결제처럼 되돌리기 어려운 작업은 AI가 초안을 만들고 사람이 최종 확인하는 방식을 권장합니다.

**Q. 거래처 사이트 로그인 정보를 줘도 되나요?**

ChatGPT 사용 시 입력한 정보는 OpenAI 서버를 경유합니다. 민감한 로그인 정보를 다룰 때는 OpenHands처럼 내부 서버에서 운영하는 도구를 권장합니다.
