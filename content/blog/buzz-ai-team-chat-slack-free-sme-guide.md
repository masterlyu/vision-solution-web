## BUZZ가 뭔지, 30초 안에 이해하기

BUZZ는 Slack처럼 생긴 팀 채팅 앱입니다. 채널을 만들고, 팀원을 초대하고, 파일을 공유하는 방식이 거의 같습니다.

다른 점이 세 가지 있습니다.

첫째, **돈이 안 듭니다.** Apache 2.0 라이선스로 공개된 오픈소스라 상업적으로 써도 무료입니다. 사용자 수 제한도 없습니다.

둘째, **AI 에이전트가 처음부터 팀원으로 들어옵니다.** 채널을 만들면 Claude, ChatGPT 같은 AI를 직원 초대하듯 넣을 수 있습니다. AI가 채팅방에서 직접 질문에 답하고, 문서를 정리하고, 초안을 써줍니다.

셋째, **내 서버에 직접 설치합니다.** 회사 데이터가 외부 클라우드를 거치지 않습니다. 고객 정보나 내부 가격 정책이 밖으로 나가지 않습니다.

## Slack이랑 실제로 뭐가 다른가요

Slack 무료 플랜은 메시지가 90일치만 보입니다. 지난달에 결정했던 내용이 어느 날 사라진 경험, 한 번쯤 있으셨을 겁니다. Pro 플랜으로 올리면 사용자 1인당 월 약 8달러(한화 약 11,000원)가 나옵니다. 직원 10명이면 매달 11만 원, 1년이면 132만 원입니다.

BUZZ는 메시지 제한이 없습니다. 과거 대화 전체가 남고, 비용은 0원입니다.

![Slack Pro vs BUZZ 비교](/images/blog/buzz-ai-team-chat-slack-free-sme-guide-fig1.svg)
*▲ Slack Pro vs BUZZ 주요 차이 비교 · 출처: BUZZ GitHub(github.com/block/buzz), Slack 공식 홈페이지*

솔직히 부족한 부분도 있습니다. BUZZ는 아직 v0.4.21 초기 버전입니다. 모바일 앱이 없고, 한국어 최적화도 Slack처럼 매끄럽지 않습니다. Slack이 10년 넘게 다듬어온 UX를 단번에 따라잡기는 어렵습니다.

그럼에도 중소기업 관점에서는 "써볼 이유"가 분명합니다. 비용 0원에, AI 에이전트가 바로 들어옵니다.

그럼 실제로 우리 회사 업무에는 어떻게 쓸 수 있을까요?

**① 반복 문의 자동 처리 — 소매·서비스업**

고객 문의 채널에 AI 에이전트를 팀원으로 넣어두면 "영업시간이 어떻게 되나요?", "환불 절차가 어떻게 되나요?" 같은 반복 질문을 AI가 먼저 처리합니다. 직원은 AI가 못 답한 특이 케이스만 확인하면 됩니다. 야간·주말 문의도 사람 없이 돌아갑니다.

**② 내부 문서 정리 — 제조·물류**

작업 지시서, 거래처 정보, 단가표를 채널에 올려두면 AI 에이전트가 요약·분류해 팀에 공유합니다. 현장 직원이 "A거래처 납기 기준이 어떻게 되지?"라고 채팅으로 물으면 AI가 내부 문서에서 찾아 바로 답합니다. 전화 돌리는 시간이 줄어듭니다.

**③ 마케팅 초안 작성 — 온라인 쇼핑몰·스타트업**

상품 소개글, SNS 문구, 이메일 뉴스레터 초안을 AI 에이전트에게 채팅으로 부탁합니다. 브랜드 톤에 맞게 정리된 초안을 받아서 검수만 하면 됩니다. 마케터 한 명이 더 많은 상품을 커버할 수 있습니다.

> **비젼솔루션 관점** — 팀 채팅에 AI가 들어온다는 건 도구 하나가 늘어나는 게 아닙니다. 사람이 사람에게 물어보던 자리에 AI가 들어서면 기다리는 시간 자체가 없어집니다. BUZZ가 흥미로운 이유는 "오픈소스라 무료"라는 사실이 아니라, 이 변화를 비용 없이 시작해볼 수 있다는 점입니다. 작은 회사일수록 실험 비용이 낮아야 빨리 움직일 수 있습니다.

## 지금 바로 설치하기 — 3단계

![center](/mascot/md/emotion/cat_cheer.webp)

컴퓨터 사양은 크게 가리지 않습니다. macOS, Windows, Linux 모두 지원하고, 설치 파일은 일반 프로그램처럼 실행하면 끝납니다. 별도 서버 없이 노트북 한 대면 시작할 수 있습니다.

**① GitHub에서 다운로드**  
[github.com/block/buzz](https://github.com/block/buzz) 접속 → 우측 `Releases` 탭 클릭 → 운영체제에 맞는 설치 파일(.dmg / .exe / .AppImage) 다운로드

**② 설치 실행**  
다운로드된 파일을 실행합니다. 일반 프로그램 설치와 동일합니다. 코드 한 줄도 입력 안 해도 됩니다.

**③ AI 에이전트 초대**  
앱 실행 후 채널 생성 → 팀원 초대 화면에서 AI 에이전트 선택 → Claude 또는 ChatGPT API 키 입력 → 완료. 채팅방에 AI 팀원이 들어옵니다.

## 자주 묻는 질문

**Q. IT 지식 없어도 설치할 수 있나요?**  
데스크탑 앱 방식이라 일반 프로그램 설치와 같습니다. AI 에이전트 연동은 API 키가 필요한데, Claude나 ChatGPT에 가입 후 발급받는 과정이 5분 이내입니다.

**Q. 회사 데이터가 외부에 나가지 않나요?**  
BUZZ 자체는 자체 PC나 서버에 설치합니다. 단, AI 에이전트(Claude, ChatGPT)에 질문을 보낼 때는 해당 AI 회사 서버를 거칩니다. 민감한 고객 정보는 직접 AI에 입력하지 않는 운영 방침이 필요합니다.

**Q. Slack에서 이전하면 기존 메시지는요?**  
v0.4.21 현재 Slack 히스토리 자동 이전 기능은 없습니다. 신규 채널로 시작하거나, 중요 내용만 수동으로 복사하는 방식이 현실적입니다.
