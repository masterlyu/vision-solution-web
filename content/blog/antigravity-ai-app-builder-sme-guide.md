"AI 에이전트"라는 단어가 낯설게 느껴지실 수 있습니다. 쉽게 말하면, **여러 단계를 스스로 판단하며 처리하는 AI 비서**입니다. 기존 챗봇은 질문에 답만 했습니다. AI 에이전트는 "월별 판매 데이터를 읽어서 팀장에게 보낼 요약 보고서를 만들어줘"처럼 여러 단계가 필요한 업무를 알아서 처리합니다.

## Google Antigravity — 지금 당장 무료로 쓸 수 있습니다

[antigravity.google](https://antigravity.google)에 접속하면 구글 계정으로 바로 로그인됩니다. 별도 설치 없이, 신용카드 입력 없이 시작할 수 있습니다.

![center](/mascot/md/emotion/cat_thinking.png)

**장점은 명확합니다.** 자연어로 업무 흐름을 설명하면 AI가 에이전트를 만들어줍니다. Gmail, 구글 드라이브, 구글 스프레드시트와 곧바로 연동됩니다. Gemini 3.8 Flash 기반이라 한국어 처리 품질도 높아요.

**단점도 솔직히 말씀드립니다.** 현재 preview 단계라 간헐적으로 불안정할 수 있습니다. 회사 내부 전산 시스템(ERP, 자체 DB 등)에 직접 연결하려면 추가 설정이 필요하고, 구글 생태계 바깥으로 나가는 순간 복잡해집니다. 보안 정책이 엄격한 곳이라면 회사 데이터를 구글 서버에 올리는 것 자체를 먼저 검토해야 합니다.

대안과 비교하면, Dify(오픈소스, 설치형)는 사내 서버에 설치해 데이터를 내부에서만 처리할 수 있어 보안에 강합니다. Antigravity는 설치 없이 바로 쓰는 편의성이 낫지만, 데이터가 구글로 올라간다는 점을 감수해야 합니다.

## 중소기업이 바로 써볼 수 있는 시나리오 3가지

하루에 반복되는 업무를 하나씩 떠올려 보세요. 아마 이 중에 하나는 해당할 겁니다.

**시나리오 1 — 고객 문의 이메일 자동 분류**

하루에 받는 이메일 50통 중 30통이 "배송 언제 오나요?", "반품 어떻게 하나요?" 같은 유형이라면? Gmail 연동으로 Antigravity 에이전트를 만들면 문의를 자동으로 유형별로 분류하고 초안 답변을 붙여줍니다. 담당자는 확인하고 발송만 하면 됩니다. 쇼핑몰, 제조업 고객지원팀, 서비스업 CS 담당자에게 특히 유용합니다.

**시나리오 2 — 주간 보고서 자동 생성**

구글 스프레드시트에 매주 쌓이는 매출·재고·방문자 데이터를 에이전트에 연결하면, 정해진 형식의 보고서 초안이 자동으로 만들어집니다. 매주 월요일 아침 두 시간이 30분으로 줄 수 있어요.

**시나리오 3 — 계약서·공문서 내용 요약**

새로운 거래처 계약서가 들어오면, 구글 드라이브에 업로드하는 것만으로 핵심 조항 5개를 정리한 요약본이 자동으로 준비됩니다. 법적 판단은 반드시 전문가에게 맡겨야 하지만, 검토 시간은 크게 줄어듭니다.

구글 계정 하나로 시작할 수 있습니다. 회원가입 추가 절차는 없습니다.

![Google Antigravity 시작 3단계](/images/blog/antigravity-ai-app-builder-sme-guide-fig2.svg)
*▲ Antigravity 시작 3단계 · 출처: antigravity.google 공식 문서*

**1단계** — [antigravity.google](https://antigravity.google) 접속 → 구글 계정으로 로그인

**2단계** — "새 에이전트 만들기" 클릭 → 하고 싶은 업무를 말로 설명합니다. 예시:

```
매주 월요일 아침에 구글 스프레드시트의 '주간매출' 시트를 읽어서
팀장 이메일로 요약 보고서를 자동 발송해줘.
항목은 전주 대비 증감, 주요 품목 TOP 3, 특이사항으로 구성해줘.
```

**3단계** — 에이전트 저장 후 테스트 실행 → 결과 확인

여기까지는 무료, 구글 계정 하나로 됩니다. Gmail·구글 드라이브 연동 이후가 막히거나, 회사 전산 시스템에 직접 붙이고 싶다면 편하게 문의해 주세요.
