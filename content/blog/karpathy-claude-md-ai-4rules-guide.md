ChatGPT나 Claude를 쓰다가 이런 경험 해보신 적 있으시죠?

"이 문단만 다시 써줘"라고 했더니 제목까지 다 바꿔버린다거나, "짧게 정리해줘"라고 했는데 오히려 더 길어지거나, 작업이 끝났다길래 확인해보니 엉뚱한 방향으로 가 있는 경우. 처음엔 AI가 멍청한 줄 알았는데, 알고 보면 **규칙을 안 줬기 때문**인 경우가 대부분입니다.

세계 최고의 AI 연구자 중 한 명인 **안드레이 카파시(Andrej Karpathy)**가 바로 이 문제를 정확히 짚었습니다. Tesla AI 총괄과 OpenAI 공동창업자를 지낸 그는, AI 코딩 에이전트가 반복적으로 저지르는 실수 패턴 3가지를 공개적으로 지적했습니다. 그리고 개발자 Forrest Chang이 이를 바탕으로 단 **65줄짜리 텍스트 파일(CLAUDE.md)** 하나를 만들었더니, GitHub에서 **20만 명 이상이 즐겨찾기에 추가**하며 역대 AI 워크플로우 파일 1위에 올랐습니다.

"AI에게 규칙을 주면 실수가 사라진다." 이 파일이 증명한 단순하지만 강력한 진실입니다.

## CLAUDE.md가 뭔가요? (초보자도 이해할 수 있게 설명드릴게요)

![center](/mascot/md/emotion/cat_thinking.png)

CLAUDE.md는 Claude Code, Cursor 같은 AI 코딩 도구에 "이렇게 행동해라"는 지침을 미리 적어두는 텍스트 파일입니다. 쉽게 말하면 **신입 직원에게 건네는 업무 매뉴얼**입니다. "우리 회사에선 이렇게 일해요"라고 먼저 알려주는 거죠.

중요한 것은, 코딩 도구에만 쓰이는 기술이 아니라는 점입니다. **ChatGPT나 Claude 채팅에서도 대화 첫 줄에 동일한 원칙을 붙여넣으면** 그대로 적용됩니다. 즉, 지금 여러분이 매일 쓰는 모든 AI 도구에 오늘 바로 활용할 수 있습니다.

## AI 실수를 막는 4가지 규칙

카파시가 지적하고 CLAUDE.md가 해결책으로 정리한 핵심 규칙 4가지를 중소기업 실무에 맞게 풀어드리겠습니다.

### 규칙 1. 먼저 생각하게 하세요 — 바로 시작 전에 계획부터

AI에게 "바로 해줘"라고 하면 대부분 성급하게 달려듭니다. 그 대신 이렇게 말해보세요.

> "작업을 시작하기 전에, 어떻게 할지 단계별로 먼저 설명해줘."

계획을 먼저 말하게 하면 엉뚱한 방향으로 달리는 걸 미리 막을 수 있습니다. 마치 목수에게 "이 선반 달아줘"가 아니라 "달기 전에 위치와 방식을 먼저 말해줘"라고 하는 것과 같습니다.

### 규칙 2. 단순하게 만들도록 하세요 — 복잡화 방지

AI는 "더 좋게" 만들려는 경향이 있습니다. 그런데 그 "더 좋게"가 오히려 문제를 키울 때가 많습니다.

> "가장 단순한 방법을 써줘. 복잡한 구조나 불필요한 기능을 추가하지 마."

중소기업 업무에 적용하면, "이 데이터 정리해줘"라고 할 때 복잡한 자동화 대신 정렬·중복 제거 같은 기본 방법을 먼저 쓰게 하는 것입니다. 간단할수록 나중에 수정하기도 쉽습니다.

### 규칙 3. 꼭 필요한 것만 바꾸도록 하세요 — 범위 이탈 방지

가장 많은 피해를 주는 AI의 습관이 바로 이것입니다. "A만 고쳐달라"고 했는데 B, C, D까지 바꿔버리는 것. 명확하게 선을 그어야 합니다.

> "내가 지정한 부분만 수정해줘. 다른 건 건드리지 마."

홈페이지 문의 버튼 색상만 바꾸려다 전체 레이아웃이 바뀌는 경험을 해보셨다면, 이 규칙이 왜 필요한지 바로 이해하실 겁니다.

### 규칙 4. 목표를 먼저 확인하게 하세요 — 성공 기준 명확화

작업이 끝났을 때 "잘 된 것"이 무엇인지 먼저 합의해야 합니다. 그래야 AI도 여러분도 같은 방향을 봅니다.

> "작업 전에 완료 기준이 뭔지 먼저 확인해줘."

고객 응대 메일 초안을 요청할 때 "자연스러운 메일"이 아니라 "50자 이내, 감사 인사·일정 확인·연락처 포함"처럼 구체적인 기준을 먼저 정하는 것입니다.

## (주)비젼솔루션이 보는 관점

규칙이 없는 AI는 영리하지만 위험합니다. 최선을 다하려는데 기준이 없으니 스스로 판단해서 움직이고, 그 판단이 틀릴 때 피해가 생깁니다. 카파시가 지적한 세 가지 패턴 — 성급한 실행, 과도한 복잡화, 범위 이탈 — 은 사실 AI만의 문제가 아닙니다. 지시를 제대로 받지 못한 사람도 똑같이 행동합니다. CLAUDE.md가 20만 명의 선택을 받은 이유는 간단합니다. 이미 알고 있던 진실을 65줄로 정리해줬기 때문입니다. **"AI는 규칙을 알면 규칙대로 일한다."** 그리고 그 규칙은 특별한 기술이 필요 없습니다. 텍스트 파일 하나, 또는 채팅창 첫 줄의 한 문단으로도 충분합니다.

## 5분 안에 바로 적용하는 실습 가이드

![center](/mascot/md/emotion/cat_cheer.png)

### 방법 1. ChatGPT·Claude 채팅에서 즉시 적용

아래 텍스트를 복사해서 ChatGPT나 Claude 대화 첫 줄에 붙여넣기만 하면 됩니다.

```
당신은 나의 업무 보조 AI입니다. 다음 규칙을 반드시 지켜주세요.
1. 작업 전에 단계별 계획을 먼저 말해주세요.
2. 가장 단순한 방법을 사용하세요. 복잡하게 만들지 마세요.
3. 내가 요청한 범위만 처리하세요. 그 외는 건드리지 마세요.
4. 시작 전에 완료 기준을 확인해주세요.
```

이것만으로도 AI의 행동 방식이 눈에 띄게 달라집니다.

### 방법 2. Claude Code에 CLAUDE.md 파일로 적용

1. **[github.com/multica-ai/andrej-karpathy-skills](https://github.com/multica-ai/andrej-karpathy-skills)** 접속 (무료 오픈소스)
2. 초록색 `Code` 버튼 → `Download ZIP` 클릭
3. ZIP 압축 풀기 → `CLAUDE.md` 파일 확인
4. **[claude.ai/code](https://claude.ai/code)** 에서 Claude Code 무료 시작
5. 작업할 프로젝트 폴더에 `CLAUDE.md` 파일 붙여넣기
6. 이후 Claude Code가 자동으로 이 4가지 규칙을 따릅니다

### 방법 3. Cursor에서 동일 적용

Cursor(무료 티어 제공)를 사용하신다면, `.cursorrules` 파일에 같은 내용을 붙여넣으면 됩니다. 효과는 동일합니다.

| 도구 | 적용 방법 | 비용 |
|------|-----------|------|
| ChatGPT / Claude 채팅 | 대화 첫 줄에 붙여넣기 | 무료 |
| Claude Code | CLAUDE.md 파일 추가 | 무료 티어 제공 |
| Cursor | .cursorrules 파일 추가 | 무료 티어 제공 |
| GitHub Copilot | .github/copilot-instructions.md | 유료 구독 필요 |
