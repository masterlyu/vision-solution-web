## Grok Bot, 뭐가 다른가요?

기존 ChatGPT나 Claude는 내가 화면 앞에 앉아서 질문을 던져야 답이 왔습니다. 대화가 끝나면 AI도 멈췄습니다.

Grok Bot은 다릅니다. 클라우드의 전용 컴퓨터가 각 봇에게 배정되고, 그 봇이 내 이메일·앱·웹사이트에 직접 로그인해서 일을 이어갑니다. 쉽게 말하면 **"메시지로 업무를 넘겨받는 AI 직원팀"**입니다.

xAI에 따르면 내부 테스트에서 영업 발굴, 마케팅 캠페인 실행, 신규 직원 온보딩, 사무 운영, 버그 수정 같은 업무를 에이전트에게 위임하는 방식으로 검증됐습니다. "동료에게 메시지를 보내듯 업무를 넘기면 된다"는 게 xAI의 설명입니다.

그런데 현실적인 문제가 하나 있습니다.

## 무료 대안 Eigent — 내 PC에서 AI팀을 운영합니다

![Eigent 핵심 3가지](/images/blog/grok-bot-eigent-free-ai-agent-guide-fig1.svg)
*▲ Eigent 핵심 장점 · 출처: Eigent GitHub(github.com/eigent-ai/eigent)*

**Eigent**는 여러 AI 에이전트가 내 PC 안에서 병렬로 업무를 처리하는 오픈소스 데스크탑 앱입니다. GitHub(github.com/eigent-ai/eigent)에서 무료로 받을 수 있고, Apache 2.0 라이선스라 상업적 활용도 자유롭습니다.

### 무엇을 해주나요?

에이전트 한 팀을 구성해 복잡한 업무를 나눠서 동시에 처리합니다. Claude나 ChatGPT API 키를 연결해 쓰거나, 인터넷 없이 내 PC에서만 돌아가는 로컬 모델도 지원합니다. 브라우저·터미널 도구가 내장되어 있어 웹 조사나 파일 작업도 자동화됩니다.

### 내 PC 사양이 되나요?

| 항목 | 요구사항 |
|------|----------|
| Node.js | 버전 18~22 (무료 설치) |
| Python | FastAPI 백엔드용 (무료 설치) |
| 운영체제 | 윈도우 / macOS / 리눅스 |
| GPU | 클라우드 API 연동 시 불필요 |

Claude, ChatGPT 같은 클라우드 AI API를 연결해서 쓰면 특별한 그래픽카드 없이도 충분합니다. API 비용은 쓴 만큼만 나가는 종량제라 소규모 활용에선 부담이 크지 않습니다.

### 솔직한 장단점

Grok Bot은 클라우드에서 24시간 계속 돌아가지만, Eigent는 내 PC가 켜져 있는 동안 에이전트가 작동합니다. 완전 무인 운영보다는 퇴근 전 업무를 맡기고 다음날 결과를 확인하는 방식이 더 현실적입니다.

대신 데이터가 외부 서버로 나가지 않아 거래처 정보나 내부 문서를 다룰 때 훨씬 안심됩니다. Grok Bot과 달리 추가 구독비가 없다는 점도 실질적인 차이입니다.

## 중소기업이라면 이렇게 씁니다

**시나리오 1 — 견적 문의 이메일 자동 정리**

하루에 견적 요청 이메일이 5~10통 온다고 가정해봅시다. 에이전트가 이메일을 읽고 "제품명·수량·납기 요청" 항목을 뽑아 엑셀로 정리해둡니다. 다음날 출근하면 표 하나가 기다리고 있습니다. 일일이 열어보는 시간이 줄어드는 겁니다.

**시나리오 2 — 신규 거래처 병렬 리서치**

"이 10개 회사 홈페이지·뉴스·SNS 조사해줘"라고 에이전트팀에 맡기면, 여러 봇이 동시에 각 회사를 조사해 요약 보고서를 만들어줍니다. 혼자 하면 반나절 걸리는 일이 짧게 끝납니다.

**시나리오 3 — 입찰 서류 초안 작성**

공고 PDF를 주고 "우리 회사 소개서 내용 참고해서 제안서 초안 잡아줘"라고 하면 1차 초안을 만들어줍니다. 검토·수정은 사람이, 구조 잡기는 에이전트가 하는 분업입니다.

## 지금 바로 해보기 — Eigent 5분 설치

![Eigent 설치 3단계](/images/blog/grok-bot-eigent-free-ai-agent-guide-fig2.svg)
*▲ Eigent 설치 흐름 · 출처: Eigent GitHub README*

**① Node.js 설치**  
nodejs.org에서 LTS 버전(18~22)을 내려받아 설치합니다. 평범한 프로그램 설치와 동일합니다.

**② Eigent 내려받기 및 실행**

```bash
git clone https://github.com/eigent-ai/eigent
cd eigent
npm install
npm start
```

명령 프롬프트(윈도우) 또는 터미널(맥)에 위 네 줄을 순서대로 붙여넣으면 됩니다. git이 없으면 git-scm.com에서 먼저 설치합니다.

**③ AI 모델 연결**  
앱이 실행되면 Claude나 ChatGPT API 키를 설정 화면에 입력합니다. API 키는 각 서비스 홈페이지에서 무료로 발급받을 수 있습니다. 처음 발급 시 소액 크레딧이 제공됩니다.

**④ 첫 에이전트 실행**  
"이 회사들의 홈페이지를 조사해서 업종과 규모를 정리해줘"처럼 자연어로 업무를 입력합니다. 에이전트가 작업 계획을 짜고 실행에 들어갑니다.

**⑤ 결과 확인**  
에이전트가 완료 보고를 올리면 결과물을 검토합니다. 처음엔 간단한 조사 업무부터 시작해 익숙해지는 게 좋습니다.

## 자주 묻는 질문

**Q. 에이전트가 실수를 하면 어떻게 되나요?**  
Eigent는 각 단계마다 사용자 승인을 요청하는 모드를 설정할 수 있습니다. 처음엔 "승인 모드"로 운영하면서 에이전트가 무엇을 하는지 눈으로 확인하는 것을 권장합니다.

**Q. ChatGPT API 비용이 많이 드나요?**  
간단한 조사·정리 업무 기준으로 하루 수천 원 수준에서 시작할 수 있습니다. 복잡한 장시간 작업은 더 들 수 있으니 처음엔 소규모로 테스트해보는 게 좋습니다.

**Q. 우리 회사 데이터가 외부로 나가나요?**  
에이전트가 사용하는 AI 모델(Claude, GPT) 서버로 분석 요청이 전송됩니다. 거래처·인사 정보 같은 민감 데이터는 직접 입력하지 말고, 요약하거나 비식별화한 내용만 다루도록 처음부터 기준을 잡으시길 권장합니다.
