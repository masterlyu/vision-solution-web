## GPT-5.6이란 — 스마트폰 요금제처럼 생각하면 된다

스마트폰 요금제를 고를 때 전화만 하는 사람이 무제한 데이터 요금제를 살 필요가 없는 것처럼, AI도 이제 용도에 맞게 고를 수 있습니다.

![center](/mascot/md/emotion/cat_happy.png)

GPT-5.6은 하나의 AI가 아닙니다. OpenAI가 성능과 가격에 따라 세 가지로 나눈 것입니다.

- **Sol** — 가장 강력합니다. **ultra 모드**에서 AI 에이전트 4개가 동시에 작동해 복잡한 리서치나 긴 보고서를 처리합니다.
- **Terra** — GPT-5.5와 비슷한 성능인데 가격이 절반입니다. 일상 업무 자동화의 균형형 선택입니다.
- **Luna** — 가장 빠르고 가장 저렴합니다. 대량의 반복 작업을 낮은 비용으로 처리합니다.

"ultra 모드"란 쉽게 말하면 직원 4명이 같은 주제를 각자 조사해 합쳐주는 것과 비슷합니다. AI 4개가 병렬로 일하는 방식입니다.

*▲ GPT-5.6 Sol·Terra·Luna API 입력 가격 비교 · 출처: OpenAI*

Terra는 GPT-5.5 대비 가격이 절반입니다. Luna는 Sol 대비 80% 저렴합니다. API를 직접 연결해 쓰는 회사라면 비용 절감이 상당합니다.

![center](/mascot/md/emotion/cat_thinking.png)

ChatGPT 플랜 기준으로 정리합니다.

| | Luna | Terra | Sol |
|-|------|-------|-----|
| **무료 플랜** | ❌ | ✅(Work·Codex 한정) | ❌ |
| **Plus ($20/월)** | ✅ | ✅ | ✅ |

1M 토큰이 낯설다면, 한글 기준 약 50만 자입니다. A4 용지 약 200~400장 분량입니다. 중소기업이 ChatGPT로 하루에 처리하는 양은 훨씬 적으니 API 비용은 예상보다 낮습니다.

**솔직한 한계:**

무료 플랜은 ChatGPT Work·Codex에서만 Terra를 쓸 수 있고 사용량 제한이 있습니다. 일반 채팅(chat.openai.com)은 Plus부터 GPT-5.6이 활성화됩니다. Sol의 ultra 모드(에이전트 4개 병렬)는 본격 활용에 API 연동이나 Pro 플랜이 필요합니다.

프롬프트 캐싱 기능도 새로 강화됐습니다. 같은 내용을 반복 처리할 때 캐시 읽기 비용이 90% 할인되고, 최소 30분 캐시가 유지됩니다. 정형화된 업무(반복 프롬프트)가 많은 회사라면 실질적인 절감이 됩니다.

다른 서비스와 비교하면, ChatGPT Plus는 Claude Pro, Gemini Advanced와 모두 월 $20 수준입니다. 다만 GPT-5.6은 세 모델 중 선택이 가능하다는 점에서 유연성이 높습니다. 특정 작업(코딩·학술 분석)에서는 Claude나 Gemini가 나을 수 있으니, 한 달씩 써보고 맞는 걸 고르는 방법이 현실적입니다.

## 업종별 선택 가이드 — 3가지 기준으로 정한다

![GPT-5.6 모델 선택 흐름도](/images/blog/gpt56-three-models-smb-guide-fig2.svg)
*▲ 중소기업 업무 유형별 GPT-5.6 모델 선택 흐름 · 출처: (주)비젼솔루션*

![center](/mascot/md/emotion/cat_cheer.png)

선택 기준은 단순합니다. 업무의 **복잡도**와 **처리 건수**, 두 가지면 됩니다.

**Luna가 맞는 회사:**
하루에 같은 종류의 작업을 많이 처리해야 할 때입니다. 제품 설명 번역, SNS 게시물 초안, 고객 문의 답변 초안 — 이런 작업을 50건, 100건씩 돌린다면 Luna가 압도적으로 효율적입니다. API 연동이나 Plus 이상이 필요하지만, 처리 건수가 많을수록 비용 대비 효과가 큽니다.

**Terra가 맞는 회사:**
대부분의 중소기업이 여기에 해당합니다. 견적서·제안서 작성, 마케팅 카피, 회의록 요약, 이메일 초안처럼 "품질이 어느 정도 되어야 하는" 업무에 Terra가 균형이 좋습니다. GPT-5.5와 성능이 비슷하면서 가격이 절반이라, 기존 Plus 사용자라면 같은 비용에 더 많이 처리할 수 있습니다.

**Sol이 맞는 회사:**
복잡한 분석이나 깊이 있는 리서치가 정기적으로 필요한 곳입니다. 경쟁사 분석 보고서, 시장 조사, 법률 계약서 검토 초안처럼 여러 정보를 종합해야 할 때 Sol의 ultra 모드가 빛납니다. ChatGPT Plus로 먼저 써보고, 자주 쓰게 되면 API 연동을 고려하는 순서가 현실적입니다.

**내 데이터와 연결하는 방법:**
API를 활용하면 회사 제품 목록, 가격표, 고객 FAQ를 AI에 넣고 자동 답변 시스템을 만들 수 있습니다. Zapier나 Make.com 같은 노코드 도구로 기본 연결은 가능합니다. 다만 기존 ERP·CRM 등 내부 시스템과 깊게 통합하려면 전문 설계가 필요합니다.
