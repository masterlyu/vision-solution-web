AI 반도체 세계 1위 기업 엔비디아가 처음으로 AI 모델을 공짜로 풀었습니다. 2026년 8월 11일 공개된 **Nemotron 3.5 Lightning**은 기업이 허가나 비용 없이 상업적으로도 자유롭게 쓸 수 있는 오픈소스 라이선스(OpenMDW 1.1)입니다. 지금까지 엔비디아는 AI 칩을 만드는 회사였지 AI 모델을 무료로 공개하는 회사가 아니었습니다. 이번이 처음입니다.

![center](/mascot/md/emotion/cat_happy.png)

그런데 "엔비디아 AI"라는 말만 들어도 "우리 회사 컴퓨터로는 무리겠지"라는 생각이 먼저 드실 겁니다. 결론부터 말씀드리면, 설치도 없이 브라우저에서 5분 안에 체험할 수 있습니다.

## 전문용어 없이 이해하는 Nemotron — 왜 4배 빠른가

AI 모델은 크기가 클수록 더 똑똑하지만 그만큼 느려지는 단점이 있습니다. Nemotron 3.5 Lightning은 이 딜레마를 영리하게 풀었습니다.

전체 크기는 300억(30B) 파라미터짜리 대형 모델인데, 실제로 매 순간 켜지는 건 30억(3B) 파라미터뿐입니다. 나머지는 대기 상태에 있다가 필요한 순간에만 활성화됩니다. 결과적으로 같은 크기의 다른 AI보다 **4배 빠르게** 작동하면서도, 한 번에 처리할 수 있는 문서 분량은 A4 약 750장에 달합니다(최대 100만 토큰).

![center](/mascot/md/emotion/cat_thinking.png)

특히 이 모델은 **AI 에이전트** 작업에 특화되어 있습니다. 에이전트란 AI가 사람 대신 여러 단계의 작업을 스스로 처리하는 방식입니다. 계약서를 받으면 핵심 조항을 찾고, 문제 있는 부분을 표시하고, 요약까지 만드는 식으로 작동합니다. 법률·계약·금융·의료처럼 문서를 꼼꼼히 다뤄야 하는 업무에 특히 강합니다.

## 두 가지 선택지 — 클라우드 vs. 내 PC

![center](/mascot/md/emotion/cat_surprised.png)

### 선택 A: NVIDIA NIM — 설치 없이 바로 (추천)

[build.nvidia.com](https://build.nvidia.com/nvidia/nemotron-3.5-lightning-30b-a3b)에서 회원가입 후 무료 API 크레딧으로 즉시 사용 가능합니다. 신용카드 없이 시작할 수 있습니다.

| 항목 | 내용 |
|------|------|
| 설치 | 없음 (브라우저에서 바로) |
| 비용 | 무료 크레딧 제공, 한도 초과 시 유료 |
| 속도 | 빠름 (엔비디아 클라우드 서버) |
| 주의 | 입력 내용이 인터넷으로 전송됨 |

### 선택 B: LM Studio — 내 PC에서 완전 무료

[lmstudio.ai](https://lmstudio.ai)에서 앱을 설치한 뒤 Hugging Face의 `unsloth/NVIDIA-Nemotron-3.5-Lightning-30B-A3B-GGUF` 모델을 다운로드하면 인터넷 없이 로컬에서 실행됩니다. 고객 데이터·계약서 등 민감한 정보를 다룰 때 유리합니다.

| 항목 | 내용 |
|------|------|
| 설치 | LM Studio 앱 + 모델 파일 (~20GB) |
| 비용 | 완전 무료 |
| 권장 사양 | RAM 16GB 이상, GPU 있으면 빠름 |
| 장점 | 데이터가 외부로 나가지 않음 |

**솔직하게 말씀드리면**: 일반 사무용 노트북에서 LM Studio로 이 모델을 돌리면 응답이 상당히 느릴 수 있습니다. 가볍게 테스트하거나 일상 업무에 바로 써보려면 NIM 클라우드부터 시작하는 편이 낫습니다.

## 중소기업은 이렇게 씁니다 — 실제 적용 시나리오

### 시나리오 1: 계약서 검토 자동화

거래처에서 계약서를 받을 때마다 법무 검토를 맡기면 비용이 부담스럽습니다. Nemotron에 계약서 전문을 붙여 넣고 "불리한 조항, 계약 기간, 위약금 조건을 요약해줘"라고 입력하면 핵심 항목을 정리해 줍니다. 법무 전문가를 완전히 대체할 수는 없지만, **어디를 집중해서 봐야 하는지 10초 만에 파악**할 수 있습니다. 반복적인 1차 검토 작업에서 시간을 크게 아낄 수 있습니다.

### 시나리오 2: 고객 문의 자동 분류·답변 초안

하루에 수십 건 들어오는 고객 문의를 직원이 일일이 분류하고 답변을 작성하는 것은 반복 소모 작업입니다. AI가 문의 내용을 읽고 유형을 분류한 뒤 답변 초안까지 만들면, 직원은 최종 확인만 하면 됩니다. 고객 대응 시간을 단축하고 담당자의 피로를 줄일 수 있습니다.

## 5분 실습 — NVIDIA NIM에서 바로 해보세요

![center](/mascot/md/emotion/cat_cheer.png)

1. **[build.nvidia.com](https://build.nvidia.com)** 접속 → 회원가입 (무료, 신용카드 불필요)
2. 검색창에 `Nemotron` 입력 → **Nemotron 3.5 Lightning 30B A3B** 선택
3. 오른쪽 **"Try it"** 버튼 클릭
4. 채팅창에 다음 프롬프트를 복사·붙여넣기:

```
다음 계약서의 핵심 조항, 불리한 조건, 계약 기간, 위약금을 한국어로 요약해줘:

[여기에 계약서 내용 붙여넣기]
```

5. 전송 후 30초 내 결과 확인

무료 크레딧 한도 내에서는 비용이 없습니다. API 연동이나 회사 업무 시스템에 붙이는 작업이 필요하다면 아래로 문의주세요.
