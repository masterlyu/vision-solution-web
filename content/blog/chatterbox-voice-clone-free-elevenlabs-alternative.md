마케팅 영상을 만들 때 가장 막히는 부분이 어디인가요? 많은 소상공인이 "나레이션"을 꼽습니다. 내 목소리는 어색하고, 외주를 맡기면 1회에 5~15만 원입니다. ElevenLabs 같은 AI 목소리 서비스를 쓰려고 가격을 보면 월 22달러(약 3만 원)부터 시작해서 손이 안 갑니다.

그런데 더 좋은 게 무료로 나왔습니다.

![center](/mascot/md/emotion/cat_surprised.png)

## 1. Chatterbox TTS가 뭔가요?

**Chatterbox TTS**는 AI 목소리 전문 기업 Resemble AI가 **무료 오픈소스(MIT 라이선스)**로 공개한 음성 복제 AI입니다. '오픈소스'란 소스코드를 공개해서 누구나 무료로 쓸 수 있다는 뜻이고, MIT 라이선스는 **상업적으로도 자유롭게 사용할 수 있다**는 의미입니다.

5초짜리 목소리 녹음 파일 하나가 전부입니다. 그 목소리로 원하는 글을 읽어주는 음성 파일을 만들 수 있습니다. 한국어를 포함해 **23개 언어**를 지원합니다. 설치 없이 웹 브라우저에서 바로 체험할 수 있는 데모 사이트도 공개되어 있습니다([chatterboxai.net](https://chatterboxai.net)).

## 2. 얼마나 좋은가요? — 수치가 말해줍니다

Chatterbox 공개 후 진행된 블라인드 테스트에서 응답자 **65.3%가 ElevenLabs보다 Chatterbox를 선호**했습니다. ElevenLabs를 선호한 응답자는 24.5%였습니다. 두 배 이상의 격차입니다.

![Chatterbox vs ElevenLabs 블라인드 선호도 비교](/images/blog/chatterbox-voice-clone-free-elevenlabs-alternative-fig1.svg)
*▲ 블라인드 테스트 선호도 비교 · 출처: Resemble AI 공식 GitHub (resemble-ai/chatterbox)*

AI 음성 모델 공유 플랫폼 Hugging Face의 TTS(텍스트-음성 변환) 카테고리에서 2025년 말 기준 **1위**를 기록했고, GitHub 스타(개발자 즐겨찾기)는 19,500개를 돌파했습니다.

특히 오픈소스 중 **최초로 감정 태그를 지원**합니다. 대본 안에 `[웃음]`이나 `[기침]`을 넣으면 그 부분에서 실제 웃음소리나 기침 소리가 함께 나옵니다. 단순 낭독이 아닌 자연스러운 표현이 가능한 이유입니다.

## 3. 우리 가게·회사에 어떻게 씁니까?

### 마케팅 영상·SNS 숏츠 나레이션

제품 소개 영상, 인스타그램 릴스, 유튜브 쇼츠에 쓸 나레이션을 직접 만들 수 있습니다. 내 목소리 그대로 자연스럽게 나오기 때문에 외주 나레이션 비용(1회 5~15만 원)이 0원으로 줄어듭니다.

### 홈페이지 음성 안내

홈페이지 접속 시 "안녕하세요, 저희 쇼핑몰에 오신 것을 환영합니다" 같은 음성 안내를 추가할 수 있습니다. 직접 녹음하면 음질이 들쭉날쭉하지만, Chatterbox로 만들면 일정한 품질을 유지합니다.

### 전화 자동 안내(ARS) 멘트

"영업시간은 오전 9시부터 오후 6시까지입니다" 같은 ARS 멘트를 직접 제작할 수 있습니다. 기존에는 전문 녹음 스튜디오에 의뢰해야 했습니다.

## 4. 지금 바로 체험 — 설치 없이 5분이면 됩니다

PC에 설치할 필요 없이 웹 브라우저에서 바로 할 수 있습니다.

**① 웹 데모 접속**
[https://chatterboxai.net](https://chatterboxai.net) 주소를 브라우저에 입력합니다.

**② 내 목소리 5초 녹음**
마이크 버튼을 눌러 5초 이상 자연스럽게 읽어주세요.
(예: "안녕하세요, 저는 ○○ 대표 ○○○입니다")

**③ 읽어줄 문장 입력**
마케팅 멘트, 상품 소개 문구, 인사말 — 원하는 내용을 텍스트로 입력합니다.

**④ 생성 버튼 클릭**
1~3초면 내 목소리처럼 읽어주는 음성 파일이 완성됩니다.

**⑤ 다운로드 후 바로 사용**
MP3 또는 WAV 파일로 저장해서 영상 편집 프로그램에 넣으면 됩니다.

> **PC에 직접 설치할 때 참고사항**
> NVIDIA GPU(VRAM 4GB 이상)가 있으면 훨씬 빠릅니다. GPU 없는 일반 PC에서도 동작하지만 생성 속도가 다소 느립니다.
> GitHub 설치 경로: [https://github.com/resemble-ai/chatterbox](https://github.com/resemble-ai/chatterbox)
