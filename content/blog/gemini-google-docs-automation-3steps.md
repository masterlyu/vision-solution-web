## Gemini CLI — 오픈소스, 완전 무료, 지금 쓸 수 있습니다

**Gemini CLI** (https://github.com/google-gemini/gemini-cli)

구글이 2025년에 공식 공개한 오픈소스 명령줄 도구입니다. 라이선스는 Apache 2.0(상업 이용 포함 자유 사용). 공개 이후 GitHub 스타 약 3만 개를 받았습니다. 터미널에서 파일을 넘기고 지시를 주면 Gemini AI가 처리해 줍니다.

이걸 **Google AI Studio 무료 플랜**과 연결하면 Gemini 2.0 Flash API를 무료 크레딧 범위 내에서 쓸 수 있습니다. 소규모 사업장의 주간 보고서 정도라면 무료 한도를 거의 넘지 않습니다.

### 쓰기 전에 알아야 할 현실

| 항목 | 내용 |
|------|------|
| 운영체제 | Windows 10/11, macOS, Linux |
| 필요 설치 | Node.js 18 이상 (무료, nodejs.org) |
| API 비용 | Google AI Studio 무료 플랜 내 사용 가능 |
| 구글 문서 직접 편집 | Google Apps Script 연동 추가 필요 (5~10줄 코드) |
| 한국어 처리 | 잘 됩니다. 한국어 프롬프트, 한국어 출력 모두 가능 |

**다른 선택지와 솔직하게 비교하면:**

- **ChatGPT API**: 거의 동일한 기능이지만 유료(입력 토큰당 과금)
- **Gemini Advanced (유료)**: 기업용 Workspace 통합 포함, 월정액 발생
- **Copilot (Microsoft)**: Excel·Word 자동화에 강하나 구글 생태계엔 별도 작업 필요
- **Gemini CLI + AI Studio 무료**: 구글 문서 생태계 사용자에게 가장 합리적인 시작점

단점도 있습니다. 터미널(명령 프롬프트) 사용에 익숙하지 않으면 처음 설치에서 막힐 수 있습니다. 아래 실습 단계를 천천히 따라오면 30분이면 돌아갑니다.

## 중소기업 주간 보고서에 적용하는 3단계

주간 보고서를 예시로 했지만, 이 패턴은 **재고 보고서·고객 문의 일일 요약·매출 분석 등 모든 정기 보고서**에 그대로 씁니다.

![Gemini 자동화 3단계 흐름](/images/blog/gemini-google-docs-automation-3steps-fig2.svg)
*▲ Gemini 문서 자동화 3단계 흐름 · 출처: (주)비젼솔루션*

**1단계 — 데이터 내보내기 (기존 그대로)**

매출·재고 시스템에서 엑셀 또는 CSV로 내보냅니다. 스프레드시트를 직접 쓰고 있다면 "다운로드 → CSV" 한 번이면 됩니다. 이 단계는 지금 하고 있는 것과 동일합니다.

**2단계 — Gemini에게 분석·요약 지시**

Gemini CLI에 CSV 파일을 건네고 지시합니다:

```
이 CSV 파일을 읽고 주간 보고서를 한국어로 작성해줘.
포함할 내용: 이번 주 주요 지표(전주 대비 증감률), 주요 이슈 3가지, 다음 주 주의사항.
비전문가도 이해할 수 있는 말투로 써줘.
```

Gemini가 데이터를 읽고 요약 단락을 생성합니다. 수치 계산과 문장 작성을 AI가 합니다.

**3단계 — 구글 문서에 반영**

처음에는 그냥 복붙해도 됩니다. "AI가 초안 → 내가 10분 검토"만으로도 2시간이 15~20분으로 줄어드는 경우가 많습니다. 더 자동화하고 싶다면 Google Apps Script를 5줄 추가하면 정해진 구글 문서 템플릿에 자동으로 채워집니다.

**내 시스템 데이터를 어떻게 연결하나요?**

회사 내부 ERP나 자체 프로그램에서 CSV 내보내기가 된다면 곧바로 연결 가능합니다. 내보내기가 안 되는 경우엔, 스프레드시트에 수동으로 붙여넣기 → CSV 저장 → Gemini 처리 순서로도 충분히 시간 절감이 됩니다.

## 직접 따라하기 — 오늘 30분이면 됩니다

### 사전 준비 (10분)

**① Node.js 설치** (이미 있으면 건너뜁니다)

```
https://nodejs.org 접속 → LTS 버전 다운로드 → 설치
```

설치 후 명령 프롬프트(또는 터미널)에서 `node -v`를 입력해 버전 번호가 나오면 완료입니다.

**② Google AI Studio에서 API 키 발급**

```
1. https://aistudio.google.com 접속 (구글 계정으로 로그인)
2. 화면 상단 또는 좌측 메뉴에서 "Get API key" 클릭
3. "Create API key in new project" 선택
4. 생성된 키를 복사해 메모장에 저장
```

**③ Gemini CLI 설치**

명령 프롬프트(Windows) 또는 터미널(Mac/Linux)에서:

```bash
npm install -g @google/gemini-cli
```

**④ API 키 연결**

```bash
export GEMINI_API_KEY="여기에-아까-복사한-API키"
```

Windows 명령 프롬프트는 `set GEMINI_API_KEY=여기에-API키` 형식으로 입력합니다.

### 첫 번째 실습 (20분)

**⑤ 테스트용 CSV 파일 준비**

스프레드시트에서 지난주 데이터를 `weekly_data.csv`로 내보냅니다. 또는 아래처럼 메모장에 간단히 만들어도 됩니다:

```
항목,이번주,지난주
매출합계,4520000,3980000
신규고객,12,9
반품건수,3,2
재고부족품목,5,3
```

**⑥ Gemini에게 분석 요청**

```bash
gemini "weekly_data.csv 파일을 읽고 주간 업무 보고서를 작성해줘. 각 항목의 전주 대비 증감률을 계산하고, 주요 이슈 3가지와 다음 주 주의사항을 포함해. 한국어로, 쉽게 써줘." --file weekly_data.csv
```

Gemini가 데이터를 분석해 보고서 초안을 생성합니다. 처음엔 약간 어색할 수 있습니다. "재고 관련 이슈를 더 구체적으로" 같은 추가 지시를 붙여가며 2~3번 다듬으면 내 보고서 스타일에 맞춰집니다.

**⑦ 구글 문서에 붙여넣기**

생성된 결과를 검토한 뒤 기존 주간 보고서 구글 문서에 붙여넣습니다. 이 단계까지만 해도 작성 시간이 크게 줄어듭니다.
